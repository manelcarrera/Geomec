GEOMEC 2D Help Index

GEOMEC 2D models can be opened or created if the registry file geomec_unlock_2dmodel.reg has been executed which installs the necessary keys into the Windows registry. 2D models are created from cross-sections within 3D models; once a cross-section has been created it will appear in the 3D model Treeview under "Cross-sections". Right-clicking over the cross-section will reveal a dialog in which it is possible to "Create 2D Model".

Once a 2D model has been created this new model can then be opened within GEOMEC. The 2D file will be recognised by GEOMEC and a different menu system and toolbar will be available specifically for 2D models.
