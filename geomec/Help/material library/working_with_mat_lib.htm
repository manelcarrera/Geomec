Working with the Material Library

 

The Material Library is the centralized location where materials and material properties are viewed and edited.

 

The main screen of the Material Library contains a list of all materials available in the library. In this list, a single material can be selected. The values of the material’s parameters are then shown in the lower list on the main screen. Clicking the same material name a second time in the top list allows you to rename the material (like in the Windows Explorer).

 

A material’s properties can be edited through the Edit button, in the Material ParametersHIDD_PARAMETERSDLG dialog.

 

Using the Import button, it is possible to import a material from another Material Library.

 

With the New button a new material can be added to the Material Library.

 

With the Delete button the selected material can be deleted from the Material Library.
