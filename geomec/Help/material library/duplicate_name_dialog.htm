The Duplicate Name Found dialog

 

A duplicate name was found while importing materials from another database. The following options are available.

 

Skip

Don’t import the material, and continue

Replace

Overwrite the existing material, and continue

Rename

Rename the material, then import it, and continue

Skip All

Don’t import the material, and all other materials with duplicate names

Replace All

Overwrite the existing material, and all other materials with duplicate names

Cancel

Don’t import the material, and stop the action
