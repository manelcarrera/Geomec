The Experiment tab (Material Parameters dialogHIDD_PARAMETERSDLG)

 

The Experiment tab is used for calibration of the material parameters through calibration.

 

Experiments can be inserted. The files contain experimental data from which the material parameters can be derived. See experiment file formatges_format for a description of the format.

 

The following fields are available.

 

Experiments

The list contains the experiments currently available for calibration.

 

Use the Insert button to insert additional experiments.

Use the Delete button to delete the selected experiment(s) from the list.

 

If a single experiment in the list is selected, the weight factor for the selected experiment can be set in the Weight factor field.

 

Picture

In the picture either all gamma’s or only the selected gamma(s) can be shown.

 

Graph

The Sigma-Epsilon option shows the sigma-epsilon graphs for the selected gammas. The P-Q options shows the P-Q graph for the selected gammas, including the yield curve for the selected Material model.
