The Material Parameters dialog

 

The Material Parameters dialog contains several parts:

 

·         the Model tabHIDD_TABMODEL

·         the Experiment tabHIDD_TABEXPERIMENT

·         the Graphs areagraphs_area

 

The Close button closes the Material Parameters dialog.

The Settings button opens the Calibration Settings window.

The Compare button starts the DIANA calibration kernel for calibration of the selected material model to the experimental datacalibrating.

The Previous button goes back to the previous material parameters in the history.

The Next button goes forward to the next material parameters in the history.
