The Model tab (Material Parameters dialogHIDD_PARAMETERSDLG)

 

The model tab contains input fields for the material’s model and parameters.

 

The following input fields are available.

 

Model

Specify the material model to be used.

 

The following material models are available:

·         Linear

·         Cam-clay

·         Mohr-Coulomb

·         Mohr-Coulomb with Linear cohesion hardening/softening

·         Mohr-Coulomb with Bi-linear cohesion hardening/softening

·         Mohr-Coulomb with Tri-linear cohesion hardening/softening

·         Mohr-Coulomb with Linear Friction Angle hardening/softening

·         Mohr-Coulomb with Bi-linear Friction Angle hardening/softening

·         Mohr-Coulomb with Tri-linear Friction Angle hardening/softening

·         Modified Mohr-Coulomb

·         Fokker Creep

·         Undrained Elastic

·         General Anisotropy

 

Input type

Specify the input mode to be used. This option allows to switch between various sets of input parameters for a same material model. This option is only available for Linear and Undrained Elastic material models.

 

Linear input type

The following options are available for the linear input type:

·         Manual

·         Dynamic stiffness

·         Bulk stiffness

·         Velocities

These input types are dependent. Making changes in the Manual type also impacts the other types, etc. The conversions used are described in Linear input type conversionslinmm_conversions.

 

Undrained Elastic input type

The following options are available for the linear input type:

·         Drained

·         Undrained

These allow to switch between drained and undrained definition for the Young’s modulus and the Poisson ratio. The conversions used are described in Undrained Elastic input type conversionsundrai_conversions.
