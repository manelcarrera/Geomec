Calibration

 

The DIANA calibration kernel calculates the radial and axial stresses to the measured experimental strain path for the selected material model.

 

For those model parameters for which the Fix checkbox is checked the value of the parameter is assumed to be fixed on the defined value. The model parameters for which the Fix checkbox is not checked are optimized such that the difference between the stresses calculated from the experimental strains and the experimentally measured stresses are minimized.

 

The algorithm looks for a local optimum and does not always result in the global optimum parameter combination. Therefore it is advised to start with calibration using simple material models such as Linear elastic and Mohr-Coulomb and transfer the calculated model parameters to the similar parameters in the more complex Modified Mohr-Coulomb and Cam-Clay model.

 

For calibration of Modified Mohr-Coulomb it is advised to check the Fix checkbox of the parameters related to the cap in the first calibration run. These parameters are:

·         Preconsolidation stress

·         Hardening parameter

 

To calibrate the cap parameters the Fix on these parameters can be removed in a second calibration run.

 

For calibration on Cam-Clay it is advised to Fix the following parameters in the first calibration run:

·         Hardening parameter

·         Cap-shape factor

 

To calibrate these parameters the Fix can be removed in a second calibration run.

 

Note     When the calibration fails go back to a simple model and try another parameter starting combination.
