Legend Geology

When the legend is in the geology mode, the legend will display the colors and names of the objects displayed in the drawing area.

The following information is displayed in the legend:

Scene

The View of the model. For Geology it can be Default, Cross section or Top View. (see Views in Model Tree for all options).

View

The information shown in the drawing area, in this case the Geology.

Geology objects

The selected part of the model in the Model tree. This can be  Horizons, Formations, Boundary, Mesh regions or Wellpaths.
