Legend area

The Legend Area is the middle vertical area displaying the legend. The legend information depends on the information shown in the drawing area. There are two possibilities:

Geology

Shows the colors of objects that are currently visualized in the drawing area (no result is visualized).

Value

Displays the value (of the visualized result) with a color gradient.

Using the Menu View the user can select between these two view modes (sometimes Value is not available).

 

Context sensitive menu

The following context sensitive menu options are available by right-clicking in the legend area. These options only appear when a value is being displayed.

Create global gradient

Creates a global color scale.

Create hotspot

Creates a hotspot color scale with.

Color scales

Overview of all the color scales: Local, global and hotspots.

Local

Activates the local color scale.

Global

Activates global color scale if available.

Hotspot

Activates a hotspot color scale if available.

Attributes

The view or change the attributes of the active color scale.
