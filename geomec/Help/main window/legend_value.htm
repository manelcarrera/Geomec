Legend Value

When the legend is in value mode, the legend will display the values with a color scale.

The following information is displayed in the legend:

Scene

The View of the model, see Views in the Model Tree.

View

The information shown in the drawing area, in this case Value.

Unit Type

Used Unit type: SI or FIELD.

Color scale

Selected Color scale. It  can be Local, Global or Hotspot.

Name color scale

Name of selected color scale.

There are two value options:

Mesh Results

A mesh result selected in the model tree.

Results

A result from a DIANA calculation, selected in the model tree.
