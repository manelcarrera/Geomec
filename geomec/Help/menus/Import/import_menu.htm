Import Menu

The Import menu contains the following items.

Mesh

Import a full 3D mesh from Gocad (SO files)

Results

Import Results from an analysis directly with Diana or Abaqus (STR or BIN files).

Surfaces

Import surfaces or faults from Gocad (TS or MX files)

Pointset / Element Sets

Import pointset or element set files (DAT, TXT, XLS, VS or MX files)

Deviated wellpath

To insert a deviated wellpath as array of AH coordinates (XLS, TXT or DAT)..
