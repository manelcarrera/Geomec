Calculation criteria

The calculation criteria dialog is displayed by selecting "Calculation Criteria" in the Analysis Menu.

A checkbox appears which shows whether or not all criteria for performing a calculation have been satisfied.

The following items are checked. If one of the criteria is not fulfilled, a red cross is displayed in front of the item, a green check if it is.

Mesh exists

Checks if a mesh has been created. Create a mesh to fulfil this item.

Reservoir assigned

Checks if a reservoir is assigned. At least one formation should have a pressure or temperature change between two subsequent depletion stages (loading of mesh).

Material properties assigned to all formations

Checks if all formations have material properties assigned to them. Assign material properties to all formations to fulfil this check.

 

 

Tetrahedron model specific

If the model currently being worked with is a tetrahedron model two additional checks are performed

Boundary conditions set

In the tetrahedron model the boundary conditions can be modified manually. This might result in a situation where insufficient boundary conditions are set on the model. This check must be fulfilled by setting additional boundary conditions at the proper nodes.
