Analysis Menu

The Analysis menu contains the following items.

Calculation criteria

Checks all the criteria required for the calculation.

Linear Depletion

Starts a linear analysis.

Nonlinear Depletion

Starts a  nonlinear analysis.

Heat Flow

Performs a Heat flow Analysis, based on reservoir boundary conditions. The analysis is performed prior to FEM computations

Mixture Analysis

Performs a combined fluid flow – FEM computation in non-linear mode for non-reservoir rocks. Option not yet active.

GVT analysis

Computes Time lapse data, based on strain and stress changes, as postprocessing step

Analysis Log

Displays the log file of the analysis.
