Linear Depletion

This command is used to run a linear elastic depletion calculation.

Use Calculation criteria to check if the analysis can be performed.

Use Nonlinear Depletion to perform a nonlinear depletion analysis, ie using Mohr Coulomb, Cam Clay or salt models..

Use create mesh to create the mesh.

 

This command can be executed by:

  • Clicking the Linear Depletion button of Toolbar Analysis.

  • Selecting Linear Depletion in the Analysis Menu.
