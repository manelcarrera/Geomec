Heat Flow

Geomec can compute Temperature changes based on conduction through rock, based on the rock properties like thermal conduction and thermal capacity, which are material properties to all material models. The method is meant to compute temperature changes (and thermal expansion as a result) in the overburden and underburden, where fluid flow is negligible and Reservoir Engineers frequently do not compute pressure or temperature changes.

 

Heat that is carried by fluid flow is neglected by the procedure, since Diana cannot accurately model multi-phase fluid flow, including phase transitions. The user should obtain temperature changes in the reservoir from the reservoir engineer and apply them as input in Geomec for all Depletion Stages.

 

All Formations that are given (user defined) pressure or temperature changes will be considered as Reservoirs. The user supplied (other than for initial Stage) data will act as boundary condition for all Depletion Stages. Initial temperature data for the bounding box of the model (the 6 bounding surfaces) will also act as boundary condition. The sea floor will hence always be a perfect heat sink or source.

 

The analysis uses the number of steps (per depletion stage) that is provided under the Non-linear analysis. Iterations are not required. The user can change the number of steps for the Non-linear FEM analysis, without invalidating the Heat Flow analysis.

 

The Heat Flow analysis is not staged. Changes in thermal conduction and –capacity imposed during a Staged (branched) approach are neglected by the analysis.
