File Menu

The File menu contains the following items.

New Model

Creates a new project. The user needs to select the element type (tetrahedron or hexahedron).

Open Model

Opens an existing project.

Save Model

Saves the current project.

Save Model As

Saves the current project with a new name and/or a new location.

Close Model Closes the present Geomec file.

Import

Imports Excel, GoCad, Eclipse, ASCII files for the Data Storage Area. Wells and Diana results cannot be imported here.

Print

Presently a disused function.

Print Preview

Presently a disused function.

Print Setup

Change the printer and printer options.

Model Attributes

Attributes of current model such as number and dates of Depletion Stages, restart options and model specifics (size, location etc.).

Recent File List

Contains a list of the four most recently used projects.

Exit

Exits Geomec.
