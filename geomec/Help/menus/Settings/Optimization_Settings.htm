Optimization Settings

 

The options below are stored in the registry and are used independent of the model that is loaded.

 

Parallel Processing during visualization

During visualization, the collecting of values, including mapping of pointsets and elementsets, can now be done in parallel. Geomec will first do a brief preparatory step, and some of the work there will also be done in parallel. This may cause the progress bar to pause for a few seconds. When the progress bar moves, Geomec is collecting the values in parallel.

·         No parallel processing (legacy)

Use the old way.

·         Partial (safe)

Only do the preparatory step. Don't use this, this is here for legacy purposes.This

·         Full

Geomec uses both the preparatory step and parallel retrieval of values.

 

Diana distributed material properties

For large models with distributed properties, Diana defines internally a new material for each element. As a new feature, it can now use one material per formation and define the distributed separately. This should lead to smaller Filos files.

·         No distributed properties (legacy)

Use the old way.

·         Distributed properties

Use the new feature.

 

Tetra Mesher

The CM2 meshing libraries replace the old FGV mesher by default. If you prefer the old one, you can still switch back. Normally, CM2 handles more input models correctly, offers better elements, and allows refinement.

·         FGV Mesher (legacy)

Use the old mesher.

·         CM2 Mesher

Use the new mesher.

 

Hexa Mesher

The new Hexa Mesher allows refinements to be selected per formation, and offers different element sizes per refinemnt. This slows the meshing somewhat, and if not needed, the old mesher would suffice.

·         Old Mesher (simple refinements)

Use the old mesher.

·         New Mesher (extended refinements).

Use the new mesher.

 

Diana Stress smoothening for DSF

With Double-Sided Faults, Stress smoothening gives much better results. You can turn it off for testing purposes.

 

Run diana in a separate process

This option may not be visible. It is highly experimental still.
