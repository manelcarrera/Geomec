Global Color scale

The Global Color scale command activates the global color scale, if a global color scale has previously been defined.

Selecting the global color scale will disable the color scale currently in use (either local or hotspot). The user may use predefined color scales or create a new scale, by redefining the minimum and/or maximum values and the choice in colors.

Use the Create global gradient command to create a global color scale.

Use Color scale in the View Menu to create, change or delete a global color scale or to define a new global color scale.

Use Attributes to view or change the attributes of the global color scale. This is only possible if the global color scale is active.

Use Local Color scale to activate the local color scale.

Use Hotspot to activate a previously defined hotspot color scale.

This command can be executed by:

  • Clicking the Global Color scale button in the Toolbar View.
  • Selecting Global Color scale in the View Menu.
  • Selecting Global in the context sensitive menu of the legend area.
  • Selecting Global in Color scale of the View Menu.
  • Select Global in Color scale of the context sensitive menu of the legend area.
