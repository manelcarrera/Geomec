View Menu

The View menu contains the following items.

Toolbar

Toggles toolbars on and off.

Status Bar

Toggles the status bar on and off.

Perspective

Toggles the perspective mode on and off.

Fill

Toggles the fill mode on and off.

Rotate

Toggles the dynamic rotation on and off.

Boundary

Toggles the bounding box of the model on and off.

Axis

Toggles the axis on and off.

Geology

Switches the view mode to geology.

Value

Switches the view mode to value.

Global Color scale

Switch to the global color scale.

Local Color scale

Switch to the local color scale.

Hotspot

Switch to the hotspot color scale.

Color Scale

Create color scales.

Options

Displays the view options.
