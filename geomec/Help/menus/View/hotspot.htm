Hotspot

The Hotspot command activates the hotspot color scale.

Selecting the hotspot color scale will disable the color scale currently in use (either local or global).

Use the Create Hotspot command to create the first Hotspot.

Use Color scale in the View Menu to create, change or delete a hotspot color scale or to define a new hotspot color scale.

Use Attributes to view or change the attributes of the hotspot color scale. This is only possible if the hotspot color scale is active.

Use Local Color scale to activate the local color scale.

Use Global Color scale to active a global color scale.

This command can be executed by:

  • Clicking the Hotspot button in the Toolbar View.
  • Selecting Hotspot in the View Menu.
  • Selecting  Hotspot in the context sensitive menu of the legend area.
  • Selecting Hotspot in Color scale of the View Menu.
  • Selecting Hotspot in Color scale of context sensitive menu of the legend area.
