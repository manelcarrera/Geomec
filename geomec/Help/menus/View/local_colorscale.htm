Local Color scale

The Local Color scale command activates the local color scale.

Selecting the local color scale will disable the color scale currently in use (either global or hotspot).

Use Attributes to view or change the attributes of the local color scale. This is only possible if the local color scale is active.

Use Global Colorscale to activate a previously defined global color scale.

Use Hotspot to activate a previously defined hotspot color scale.  

This command can be executed by:

  • Clicking the Local Color scale button in the Toolbar View.
  • Selecting Local Color scale in the View Menu
  • Selecting Local in the context sensitive menu of the legend area.
  • Selecting Local in Color scale of the View Menu.
  • Selecting Local in Color scale in the context sensitive menu of the legend area.
