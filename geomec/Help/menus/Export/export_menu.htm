Export Menu

The Export menu contains the following items.

Export Linear Depletion Input Files

Creates linear data and command files for a DIANA linear analysis.

Export Nonlinear Depletion Input Files

Creates nonlinear data and command files for a DIANA nonlinear analysis.

Export Heat Flow Input Files

Creates run files for a Heat flow computation in Diana

Export Mixture Flow Input Files

Creates run files for coupled Fluid flow and mass (FEM) flow computation in Diana

Export Results

Export Results as pointset or element set

Export Gocad Results

Export Results as properties on a Gocad mesh (SO format)

Export SVS Results

Export Principal Stresses and pressures on element midpoints, to be read in by SVS

Export Surfaces

Export Gocad surfaces as TS or MX file.

Export quadratic order data file for DIANA analysis

Converts elements to quadratic order elements and creates a DIANA data file.
