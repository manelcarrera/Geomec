Eclipse model

An Eclipse model is imported from an existing mesh created by the external Eclipse reservoir simulator program. The file format is described in Eclipse / Grid file.

Eclipse models are converted to tetrahedron type GEOMEC models. The grid from the Eclipse file is the sub-model and a super-model can be generated to extend the model, e.g. by adding an overburden to it.

To create an Eclipse model, click File -> New, and the New Model dialog appears. Select "Eclipse" and click OK.

In the Open dialog, select an Eclipse model file, and click "Open". After the file has been read in successfully, the "Select horizons from Eclipse file" dialog appears. This dialog lists all horizons detected in the imported Eclipse file. These horizons are deduced from the number of layers found in the Eclipse file. By default, all horizons are selected.

Unselect the horizons that should not be taken into account. Note that at least two horizons should be selected. Click OK to generate the Eclipse model.
