Point/Elementsets in the Point/Elementsets branch

In the point/elementsets branch in the data storage tree all the imported or created distribution sets are listed as sub branches (2D sets in the 2D sub-branch and the 3D sets in the 3D sub-branch). In the 3D sub-branch the mesh is present as a leaf.

Context sensitive menu

Right-clicking on a point- or elementset displays the following context sensitive menu:

Export

To export the pointset to a file.
Copy Copies the point/elementset to the clipboard.
Paste Not available.

Delete

Deletes the point/elementset.

Attributes

To view the point/elementset attributes.
