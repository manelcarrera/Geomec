Data storage tree

Context sensitive menu

Right-clicking on Data storage in the data storage tree displays the following context sensitive menu:

Import

Opens a file dialog in which the user can select ASCII, Excel or GoCad Eclipse files to import.

Branches

The data storage tree consists of the following branches:

  • Casing Grade.  Contains the materials for the well paths using the DCasint application.  This leaf is only visible when DCasint is enabled.
  • Point/Elementsets branch. Contains all the 2D and 3D pointset distributions.
  • Rock materials branch. Contains the materials available for use with the model and any material parameter distributions.  New materials can also be created.
  • Surfaces. Contains all the surfaces created from pointsets.
