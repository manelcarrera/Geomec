2D Point/Elementsets

A 2D point- or elementset is a data set in which for each point the Northing and Easting coordinate is defined. The Depth coordinate is undefined, unless the value belongs to the coordinate of a surface. The prefered depth tag for a surface is Surface (in stead of Depth). Assigning a 2D distribution to a Formation will result in the values being assigned to every Depth coordinate for per given Northing and Easting coordinate within this Formation. Especially when the depth variation is small (thin layers) a 2D pointset saves on memory and processing time.
