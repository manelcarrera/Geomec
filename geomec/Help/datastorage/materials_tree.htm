Rock material

Rock material is a branch of the Datastorage tree. It provides information about the material models, both in the Geomec GMP file and external material libraries (GML files).

Context sensitive menu

Right clicking on Rock material in the datastorage tree displays the following context sensitive menu:

From material library To select a material from the (last addressed) material library.
Show material library Displays all materials currently held in the (last addressed) material library.
Select material library Browse to folder and GML file where the required material data are stored. This file becomes the "last addressed" library.
Create material library To create a new (empty) material library. This file becomes the "last addressed" library.

Attributes

Opens the internal (GMP) material library to view or edit the materials shown under "rock material".

Refer to Working with the Material Library for further information.
