Mesh, Data Storage

The mesh is present as a leaf in the 3D sub-branch of the point/elementsets branch in the datastorage tree.

Context sensitive menu

Right-clicking on the mesh displays the following context sensitive menu:

Copy Copies the mesh to the clipboard.
Paste Not available
Delete It is not possible to delete the mesh

Attributes

Displays general information about the mesh: number of nodes, number of elements in the mesh.

Prime use is the export of data on the mesh element set.
