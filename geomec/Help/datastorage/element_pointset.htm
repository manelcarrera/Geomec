Elementset

An elementset is a listing of node numbers (with coordinates) and a subsequent listing of element types and numbers with their node numbers.

Elements that share a node number are hence connected. A single node will for instance usually appear 8 times in a hexahedron (brick) model. For a tetra-model the number of shared nodes is much less defined.

An element set may contain input or output data, attached to the nodes of an element.
