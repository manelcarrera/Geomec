Surface in surfaces branch

The surfaces branch of the data storage tree contains all surfaces created from a pointset.

Context sensitive menu

Right-clicking on a surface displays the following context sensitive menu:

Create Horizon

Creates a horizon from the surface. The newly created horizon is put in the horizons branch in the model tree.
Export To export the surface to file.
Copy Copies the surface. (not supported yet)

Delete

Deletes the surface from the surfaces branch. The surface as a pointset attribute in the point/elementset branch is also removed. 

Attributes

To view/change the surface attributes.
