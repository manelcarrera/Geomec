Surfaces

Surfaces is a branch in the data storage tree and contains all surfaces from

  • pointset surfaces (imported or calculated with the calculator on a 2D pointset) for Hexahedron models
  • triangulated surfaces (gOcad format) for Hexahedron or Tetrahedron models. For Hexahedron models, the triangulated surface will be read in as a pointset.

 

Hexahedron model

Surfaces can be manipulated to Horizons in 3 ways:

1. Right-clicking on a specific surface displays the following context sensitive menu:

Create Horizon

Creates a horizon from the surface. The newly created horizon is put in the horizons branch in the model tree.

The option disappears if the surface is attributed to a horizon.

Export

To export the surface to file.

Copy

Copies the surface (not yet supported)

Delete

Deletes the surface from the surfaces branch. The surface cannot be deleted as long as the corresponding Horizon has not been deleted 

Attributes

To view/change the surface attributes.

 

2. Right-clicking on the “surface” header displays the following context sensitive menu:

Export surfaces

To export multiple surfaces to file via a submenu.

Delete unused

To delete surfaces from the file, which have no further use to the model

Create Horizons

Creates multiple horizons via a submenu. The newly created horizons are put in the horizons branch in the model tree.

Merge Surfaces

Allows two separate surfaces to be joined to one, for instance surfaces from separate pointsets.

Cut surfaces

Cuts off any section of a surface that is outside the bounding box (Defined under “Boundary”).

Attributes

To view/change the surface attributes.

 

3. Right Clicking on “Horizon” in the model tree allows to “Create Horizon”. A surface can be chosen, or a constant-depth surface (the depth must be supplied).

The bottom of the model (some distance below the reservoir) should be flat and a fixed depth surface is advised.

PS  As a pointset surface does not cover the full extent of the model (defined under “boundary”), then the surface gets extended horizontally via a nearest neighbour policy. Trends (inclination) is hence not copied and layers will be horizontal outward.

 

Tetrahedron model

Surfaces can be manipulated to Horizons in 2 ways:

1. Right-clicking on a specific surface displays the following context sensitive menu:

Insert side surface in sub model

Creates a (near) vertical side surface horizon from the specific surface within the “Gocad submodel” tree.

The option disappears if the surface is already attributed to a horizon.

Insert Horizon in sub model

Creates a horizon from the specific surface in the Gocad submodel. The top and bottom (outer) surfaces also need to attributed as a horizon. The option disappears if the surface is already attributed to a horizon.

Surfaces must end on other surfaces or faults, i.e. may not contain “isolated edges”

Insert Horizon in super model

Allows the creation of hull around an existing model, for instance if the GoCad model only describes the reservoir and the caprock. The hull creates its own side boundaries, just like the Hexahedron models. Feature is still in experimental stage.

Insert Fault in sub model

Creates a fault in the Gocad submodel, which will be lined with interface elements to allow fault slip. If surfaces contains isolated edges, Geomec may still be able to mesh if the surface is attributed as Fault.

Copy

Copies the surface (not yet supported)

Delete

Deletes the surface from the surfaces branch. The surface cannot be deleted as long as the corresponding Horizon has not been deleted 

Attributes

Allows changing of the name (and colour of unattributed surface)

 

2. Right-clicking on the “surface” header displays the following context sensitive menu:

Export surfaces

To export multiple surfaces to file via a submenu.

Delete unused

To delete surfaces from the file, which have no further use to the model

Create Horizons

Creates multiple horizons via a submenu. The newly created horizons are put in the horizons branch in the model tree.

Merge Surfaces

Allows two separate surfaces to be joined to one, for instance split surfaces that share nodes (like side surfaces).

Cut surfaces

Cuts off any section of the surfaces that are outside the side surfaces (bounding box). Method  recomputes the intersecting nodes of the surfaces and the bounding box. Mainly used for the zoom-in box

Attributes

To view/change the surface attributes.

PS  Triangulated surfaces (including faults) must always share nodes at their intersection. Only in case of side surfaces, Geomec is able to recompute intersecting nodes by choosing the “Cut surfaces” command.
