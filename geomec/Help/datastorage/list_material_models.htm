Rock material

In the Rock material branch in the data storage tree all the created materials are listed as leaves.

Use attributes of materials to open a dialog which lists all the created materials available for use with the model.  This dialog also allows the creation of a new material.

Context sensitive menu

Right-clicking on a material displays the following context sensitive menu:

To material library

Inserts the material into the general material library.

Attributes

To edit, delete or create a material.
