3D Pointsets

A 3D point- or elementset is a series of Northing, Easting, Depth coordinates, with or without associated data.

A pointset can be created by Geomec (right click: Data Storage \  Point/element sets \ Create Pointset), by the user itself (for instance in Excel) or by external programs (such as reservoir simulators, usually as TXT or DAT files).

Externally created pointsets usually need some editing to create proper headers:

  • Make sure that the first (non-empty or non-comment) line contains the word Pointset
  • Make sure that the second (non-empty or non-comment) line contains the words UNIT SI or UNIT FIELD
  • Make sure the data is in the order Easting, Northing, Depth, values   or  Northing, Easting, Depth, values.
  • Make sure the data header at least contains the Tags Easting, Northing, Depth   or  Northing, Easting, Depth.
  • Comment out (with # or * )  all other text and data not being the pointset itself
  • Put an END statement at the last line.
