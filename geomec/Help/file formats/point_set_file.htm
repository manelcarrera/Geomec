Pointset file

The pointset format has three formats

  • Untagged format Consists of rows of numbers without any keywords. It is explicitly assumed that the first column is Easting and the second column is Northing.  

  • Tagged format Consists of rows of numbers with keywords of the correct format.

  • Gocad format.  Any 3D pointset that adheres the Gocad pointset format. It is explicitly assumed that X=Easting, Y=Northing and Z=Depth, where Z can also be upward, depending on the Gocad-axis definition, if the line “Depth = Upward” is in the text lines preceding the data.

The comment tags of the pointset format are “#” and the “*” character.
