Tagged format

The tagged format for the pointset always starts with the keyword POINTSET to distinguish between point sets and element sets.

The keyword UNIT is optional (but advised) and can have the following values:

UNIT  FIELD

The unit of the file is field.

UNIT  SI

The unit of the file is SI.

If no unit is specified, the unit is set to SI. In EXCEL, make sure that the words UNIT and FIELD or SI are in separate cells.

When using EXCEL you can use multiple Tab-sheets with data. A single sheet may contain data rows with several types of input or output per coordinate. You can leave the formulas leading to the pointset in the cells. Geomec will take the value that results from the formula (as shown by Excel when not editing) and not the formula. You can use additional calculation lines to arrive at the pointset, but make sure that you use the first column to comment the line out (with a #), so Geomec will ignore the line.

The keyword PROPERTY is optional and defines the properties in the point set. The property is defined by a type(<TYPE>) which can be found in Tags for data. A type which requires one column like a pressure for instance is followed by a column name(<COL_NAME>). The column name must be unique and is used in the header to specify the column in the point set data. The column name is also the name of the property in the pointset.

PROPERTY <TYPE> <COL_NAME>

If a property is unknown to Geomec (for instance Resistivity), but is intended to be correlated to a Geomec parameter, the user can choose “Unknown”. The line would become “PROPERTY Unknown Resistivity”. Geomec has no knowledge of units in this case and assumes unitless. All unknown parameters have to be manually assigned to a parameter, with or without the use of the RPN Calculator to make the necessary correlations.

Some group types (vectors, tensors and fracture densities) require multiple columns. A stress tensor requires six (random but unique) column names and a property name. The property name becomes the tensor name.  If the property name is omitted, the tensor/vector name will be equal to the first data column name.

The order of the tensors or vectors in mandatory:

Tensors:  NN, EE, VV, NE, EV, NV (=NN, EE, DD, NE, ED, ND)

Vectors:   N, E, D

Each coordinate keywords may only appear once. Of the coordinate keywords only the 'Depth' keyword is optional (determines whether the set will be 2D or 3D), the Northing and Easting columns are required. All keywords the must refer to column names defined by the properties in the case that the property keyword is used.

The user can add Units to the data file as last entry of the Property Line. When the unit is known to Geomec, the UNIT SI or UNIT FIELD statement will be ignored. The unit will be converted into Geomec SI-standards. For instance “bar” will be translated to “MPa” by dividing by 10. The alternative units are (SI/Field defaults between brackets)

-Displacement (not coordinate !) : inch, cm, mm (m, ft)
-Stress/pressure: bar, kbar, ksi, kpsi, Pa, GPa (MPa, psi)
-density:  g/cc, g/cm3, t/m3 (kg/m3; ppg)
-viscosity: P, MPas, Pas (cP)
-permeability:  D, m2 (mD)
-Temperature/thermal activation: K,F (C)
-Heat conductivity:  W/mK, W/mF, W/ftK, W/ftF, cal/smK, cal/sftF  (W/mC)
-Heat capacity kJ/kgC, kJ/kgC, cal/kgC, cal/lbF, kcal/lbF  (J/kgC)

Other alternative conversions might  be added in time.

When the PROPERTY keyword is not used (at all), types could be directly used in the header. See Tags for data for a complete list of all possible types. The properties will appear under their type name in the point set which makes it hard to distinguish several properties of the same type. It is advised not to import more than one set of identical properties, not to confuse data afterwards. 

Commas, tabs or spaces separate the numbers. The file should always end with the keyword END.

Depletion Stage Dependent parameters

 

Pressure, temperatures and volume strains can be assigned per Depletion Stage. If the model contains Restarts (Phases or Branches), also material parameters can be Depletion Stage dependent. When the user makes sure that the Property name ends on the (internal) depletion name tag (_Dx, with x=0...100), the pointset can be dropped on a Formation. The Depletion Stage parameters will then only be attached to that specific Depletion Stage. A parameter like Pressure_D1 can still be dragged and dropped to other Depletion Stages, like D2. In the example below, the unit for P1_D3 will be assumed psi (since UNIT=FIELD)

Unknown Parameters or unknown units

 

If Geomec reads in parameter or units, that it cannot understand (for instance Resistivity with Unit Ohm) or cannot partially understand (unit BTU instead of Joules or mmHg instead of MPa), the data will be read in as an unassigned parameter. The user can create correlations himself with the Calculator to transform the unit into Geomec-SI. Geomec SI are the units that appear in the Material Library data import when the model is in SI-display. Densities have to be converted to kg/m3, even if the display is in FIELD (with ppg as unit).
