Elementset file

The tagged format for the elementset always starts with keyword ELEMENTSET to distinguish between the pointset and elementset format. The keyword UNIT pinpoints whether FIELD or SI units are used for the associated Data. Note that the set may contain SI coordinates with FIELD data or FIELD coordinates with SI data. This procedure is not recommended, but data as such might be required in some cases. This can be set in Export and Data Storage area if necessary.  

UNIT  FIELD

The unit of the file is field.

UNIT  SI

The unit of the file is SI.

When the unit keyword is not defined the SI unit system is taken as the default.

An element set is a total (or selection) of all the elements, the nodes which are attached to it, the coordinates of the nodes and (usually) data values which are attached to the nodes. One can hence import or export data via an element set. The import function is only possible on an identical mesh, usually a data modification from an earlier export.

The format of an elementset is as in the example

  1. header "ELEMENTSET"

  2. unit definition, either "UNIT <tab> SI" or "UNIT <tab> FIELD"

  3. header "POINTS"

  4. list of all the nodes, with header "Index <tab> Easting <tab> Northing <tab> Depth"

  5. header "ELEMENTS"

  6. per type of element: element name (see table)  "ELEMENT <tab> [elementname]"

  7. per type of element: a header "ElementNr <tab> NodeIndex <tab> [valuetype1] <tab> [valuetype2] <tab>... [valuetype-n]"

  8. listing of all the elements and associated nodes with format:  "[elementNr] <tab> [NodeIndex] <tab> [value1] <tab> [value2] <tab> ... [value-n]"

  9. line "END"

  10. comment tags are the  “#” and the “*” character

It can be seen that in this set up, a single node can have multiple values, equal to the number of connected elements. For displacements these values need be identical, for other values, such as a shear stress or a Young's modulus, they can differ, since they basically represent a part of an element rather than the node itself.
