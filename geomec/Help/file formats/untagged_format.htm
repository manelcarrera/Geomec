Untagged format

The untagged format consists of rows of N numbers without any keywords. The order of the first two columns ought be Easting (column 1) and Northing (column 2). If more than 2 columns are present, the user will have to answer the pop-up question whether to treat the 3rd column as Depth (3D pointset) or not (2D pointset with 3rd column a data column).
