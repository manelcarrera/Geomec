The experiment file format

 

Experiment files are Excel format files (or txt file formats). The Material Library can read an Excel file containing multiple sheets. If more than one sheet is found in a file, the Select sheet dialog is shown where the sheets can be selected that should be loaded.

The following data are required for each step, including the allowed units as Header:

·           Time (days, hrs, min, s). If column is empty time=0 will be assumed. Plasticity models do not apply time for calibration.

·           Axial stress (Pa, kPa, MPa, psi, bar)

·           Radial stress (Pa, kPa, MPa, psi, bar)

·           Pore pressure (Pa, kPa, MPa, psi, bar). If column is empty, pore pressure=0 will be assumed.  

·           Axial strain (-)

·           Radial strain (-)  

Example:

s MPa MPa MPa strain strain or formula
  10 10   0 0  
  15 10   0.002 -0.0002  
  20 10   0.005 -0.001  
  30 10   0.01 -0.0049  

 Column 7 (Column F) and higher are not read in and can be used for calculations or can contain the original data from the test. If one puts axial strain in column K in millistrain, one can feed column E with a formula, (E7=K7/1000) to match the required format.

It is wise to start the strain levels at 0 and reset all original data to this nullification.
