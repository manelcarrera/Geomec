The Excel file format

Excel files can be used to describe:

  • Pointset files
  • Elementset files

The excel format is defined similarly to the ASCII file format.

Note that GEOMEC can only read or write Excel files if Excel is installed on the system.

 

Excel well file format

The Excel or ASCII well format is very similar to a pointset input. The input requires a pointset with Northing, Easting and Depth from top to bottom (i.e. no random order). The well name is picked from the file name (and in Excel the TAB name). The well data need to be followed with an END statement in EXCEL. Multiple wells can be inserted this way on multiple TABs. Northing and Easting may be switched in order.

A column with AHD (along hole depth) or TMD (true measured depth) may be present but will be ignored. Geomec calculates the AHD itself and adds a column when results are being exported on a well. Presently the AHD in the first point is always zero. In future releases the offset AHD can be set by the user, since the supplied top point may not be the well head location.

Unit and SI (or Field) need to be in different cells (Excel) or separated by a {tab} (not a space) in Txt files.

UNIT     SI  (or UNIT      FIELD)
Easting Northing DEPTH   {AHD }
40      40      -200    {0}
