Elements

At this moment two Body (3D) elements are possible within Geomec depending on the model type:  Hexahedron brick elements (with 8 corners / nodes) and Tetrahedron pyramid elements (with 4 corners / nodes).

Hexahedron type model

The Hexahedron brick model is preferred for simple layered systems, i.e. without fault related steps, anticlines and stratification with wedges. Furthermore, hexahedrons cannot be used when layer interfaces (=horizons) are defined as triangulated surfaces, for instance created with GoCad.

The Hexahedron model allows for mesh refinement in zones of interest, for instance the area of depletion. In this case a horizontal surface (mesh) region must be created, which refines the mesh (over the full depth) by increasing the number of elements by a factor within the selected area. 

To model the behavior of slipping horizons four-noded interface elements are used.

Tetrahedron type model

The use of Tetrahedrons is necessary to be able to mesh from GoCad or other 2D meshed surfaces with triangles. Also, in the case of wedges (sharp corners at faults or layers which wegde out), only Tetrahedrons are able to mesh these layers while being able to respect the user supplied interfaces and surfaces (stratification or faults).

To model the behavior of slipping horizons and faults three-noded contact elements are used.
