Element to element mapping

It is assumed that values available in the nodes of a given element mesh (the source mesh) can always be transferred to the nodes of another element mesh (the target mesh) which may be unrelated to the source mesh. To accomplish this, two methods are possible:

  • nodal interpolation

  • weighted mapping.

Both methods support the following condition:

When values are mapped from a source mesh to a target mesh, and the meshes are equal (co-located), the values in the target mesh should be equal to the values in the source mesh.
