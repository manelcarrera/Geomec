Zoom-in technique

Zoom-in is a scaling down technique using mixed boundary conditions. The displacements and stresses retrieved from a large scale model are applied to the boundary of the small scale model (zoom-in model). Discrepancies between the stress-displacement response of the zoom-in model and the prescribed stress-displacement boundary conditions are compensated for by using interface elements. The stiffness of these interface elements represents the stiffness of the surrounding rock.

The zoom-in technique includes the following components:

  • The boundary faces of the zoomed-in model are lined with interface elements.
  • The outer face nodes of the interface elements are supported. The displacements predicted by the larger model are applied to these nodes.
  • The stresses of the larger model are applied on the inside faces of the interface elements.
  • The stiffnesses of the interface elements are based on the analytical solution for the stiffness of a cylinder in an infinite space. Geomec applies the average model (brick) size  R ( =(L+W+H)/6 ) instead:
  • K-rad = K-normal = 3.04 * G / R
  • K-tan = K-shear  = 1.56 *  G / R  @  ½ * K-normal

This is only possible for tetrahedron models.
