Mapping routines

In GEOMEC, it is possible to generate or import pointsets and elementsets, possibly containing values. Values defined on one set can be transferred to another set. If these two sets (the source and the target) do not match exactly, values in the source set must be mapped onto the target set.

The way the obtained values are transferred to the target set depends on the set from which the values are retrieved:

Pointset

Retrieving values from a pointset is carried out using the nearest neighbor method.

Elementset

From elementsets, values are retrieved by interpolation. The interpolation method depends on whether the values are for single points or for an elementset
