Non-smoothed point interpolation

This interpolation method returns the most accurate values possible. If a point inside an element is given, the interpolation will use the nodal values of the element to derive a value for the point.

Only when the point lies on an element boundary or on a node, attached to 2 or more elements, averaging needs to be done. The averaging is only performed on the values available in the given point (i.e. from the adjacent elements). One of the following three methods is used.

  • non-weighted

  • volume weighted

  •  inverse volume weighted
