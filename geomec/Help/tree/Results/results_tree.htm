Results branch

Results is a branch in the model tree. The results branch contains all calculated results.

The results branch contains the following sub-branches:

Depletion stages Represents the depletion stages. Each result has a value for each depletion stage. The depletion stages are defined in the Depletion stages tab.

Linear/non-linear

 Represent the type of analysis: Linear or Nonlinear. Each result has a value for each analysis type.

Displacements

Represents all displacements.

Stresses

Represents all stresses and stress related results.

Pore Pressure

Represents all pore pressures and pore pressure related results.

Strains

Represents all strains and strain related results.

Optimum mudweight

Represents the results from a DStabor calculation.

DCasint

Represents the results from a DCasint calculation.

Fault

Represent fault specific results.

 

Context sensitive menu:

Export results

To export results to a file.

Import results

 To import a results file.
