Pore pressure

The pore pressure branch in the result branch is used to visualize the pore pressures for the depletion stages.

The pore pressure branch contains two leaves:

Absolute Select this result to display the pore pressure for the selected depletion stage. Pore pressures are not calculated results, since they usually are supplied by the user.
Change Select this result to display the change in pore pressure for the selected depletion stage relative to the initial depletion stage.
