Fault results

The fault branch in the results branch contains all the fault related results. Fault related results are only displayed when a fault or slipping horizon is selected.

Branches

The fault branch contains three other branches:

Relative displacement

Contains all the relative displacement results for a fault (top node minus bottom node)

Stresses

Contains all the stress results for a fault.

Pore Pressure

Contains all the pore pressure results for a fault.

Relative displacement

The relative displacement is divided into:

Dilatation

(elastic) Fault opening or closure (dilatation).

Vector

Contains the relative displacement components (Northing, Easting, Depth) as well as the total relative displacement (Length), including dilation

Plastic slip

The relative displacement is divided into:

Vector

Contains the non-elastic relative displacement components (Northing, Easting, Depth) as well as the total non-elastic displacement (Length) as well as a vector-arrow (Full Vector)

Stresses

The fault stresses are divided into:

Shear capacity

Provides the shear capacity results (shear stress to maximum shear stress ratio), Not available for full slip.

Absolute

Contains  total and effective normal stress results and shear stress. Shear stress components in direction  (Northing, Easting, Depth) and the total shear stress (Length). Not available for full slip

Change

Contains  changes in total and effective normal stress and shear stress.

Pore Pressure

The fault pore pressures are divided into:

Absolute

Contains the absolute value of pore pressure for a fault.

Change

Contains the change in pore pressure (relative to the initial stage).

For a technical definition of results see results theory.
