Strain results

The strains branch in the results branch contains all  the strain (related) results.

The strain branch contains two main sub-branches:

Total

Contains all the strain results, i.e the sum of elasto-visco-plastic deformation and thermal expansion.

Plastic

Contains all the plastic strain results, resulting from all the non-linear mechanisms including creep. These results are only available after a non-linear analysis.

The strain results are divided into:

Components

Contains all the strain components (NN, EE, DD, EN, ED, ND) and the full tensor as represented as a beach ball.

Principal Directions

Contains the maximum, medium and minimum principal total strain values. Either a component can be selected (Northing, Easting, Depth) or the total value (Length) or the Vector

Invariants

Contains the different total strain invariants: Volumetric strain, I2, I3 and the Von Mises strain.

Wellpath axial

The strain in the axial direction of a well. Only valid in Well’s View
