Mesh Results

Mesh Results is branch in the the model tree.

The following mesh results are available:

Depth

To display the depth coordinates.

Max edge length

To display the maximum edge length per element.

Average edge length

To display the average edge length per element.

Area

To display the surface area per element.
Volume To display the volume per element.
Min/Max edge ratio To display the ratio of minimum to maximum edge length per element.
Maximum angle To display the maximum angle between two edges per element.
Minimum angle To display the minimum angle between two edges per element.

Shape Factor

To display the shape factor per element.
