User defined results

The definition of user defined results are stored in the computer registry and are accessible on the same computer only, but for any model. The model is meant for the definition of non-standard units (like stresses in bar) or combination of results (for instance strain energy: a multiplication of stress and strain).

Right-clicking the user defined results branch in the model tree displays the context sensitive menu with the option 'create result'. Selecting this option launches the RPN-calculator. When the calculator is launched from the user defined results tree, only globally derived results can be generated, which are stored in the computer’s registry. In this case the following items can be used:

·         X-coordinates (Easting), Y-coordinates (Northing), Z-coordinates (Depth).

·        Manipulations on results (like stresses, strains, deformation, etc).

·        Manipulations on element properties, like assigned material properties, for instance Young’s Modulus

·        Previously defined user defined results, per depletion stage and per analysis-type.

Double click the <new results item> or <new material item> to select a result or material property.

The user can select a specific stage (for instance Depletion Stage 0, initial) and Results type (for instance Non-linear), so that the item is not dependent on the view or export selection of the stages.

A specific formula could be:    StressVV - StressVV_D0_N

The result would depend on the selected Stage and Analysis type, but would render Zero (0) for view or export selection D0 (initial) and Nonlinear Results, assuming a non-linear computation has been performed.

Warning:  the RPN calculator only works on the internally stored Geomec SI units, which are combinations of MPa, m, kg, ºC, K, cP, mD, W, J, s  !!!!  The calculator is unaware of resulting unit of any computation and will simple deduct 2 MPa from 3 m to arrive at 1 (unit unknown).

 

Model specific results should be generated by Derived Results
