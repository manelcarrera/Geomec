Material in formation branch

Formation material parameters are assigned at the material leaf in the formation branch. When no material properties are attached to the formation NONE is displayed for the material leaf.

Use the Material Library in the Data storage tree to create a new material. Newly created materials are available in the Material branch in the data storage tree. The material can be dragged and dropped onto the material leaf in a formation.. One material can be assigned to multiple formations.

Context sensitive menu

Right-clicking the material displays the following context sensitive menu:

Copy

Copies the material, it can be pasted on a material leaf of another formation.

Remove from formation

Removes assigned material from the formation.

Attributes

Displays the material library.
