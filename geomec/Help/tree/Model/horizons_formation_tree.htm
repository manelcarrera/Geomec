Horizons (branch of Formation tree)

The horizons branch in a formation branch represents the horizons from which the formation is defined.

Context sensitive menu

Right-clicking the horizons branch in the formation branch displays the same context sensitive menu as for Formation.

Branches

The horizons branch contains the top and bottom horizon of the formation as sub-branches. These horizons can also be found in the horizons branch of the model tree and have similar context sensitive menus. Deletion of these horizons can only be done in the horizons branch of the model tree.
