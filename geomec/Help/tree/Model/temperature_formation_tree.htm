Temperature

The temperatures per depletion stage are shown in the formation branch. Default temperatures are taken from the branch "Global Temperature" for both the initial stage and all subsequent depletion stages. The default global temperature is 15° Celsius with a gradient of 0.02° C/m depth.

The number of depletion stages (equal for all formations) are specified in the tab "Depletion Stages" of "Model attributes".

By selecting "Attributes" per formation and per depletion stage, a user can modify the temperature values or import temperature files via the use of point/element sets.

The branch in a formation branch represents the temperatures for the different depletion stages of the given formation.

Context sensitive menu

Right-clicking on temperature displays the same context sensitive menu as for Formation.
