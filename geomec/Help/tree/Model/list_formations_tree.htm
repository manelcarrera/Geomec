Formation

All formations are listed as branches of the formations branch in the model tree.

A formation uses the name of its top horizon as the formation name by default. Use attributes of the formation to change the name.

Context sensitive menu

Right-clicking on a formation (name) displays the following context sensitive menu:

Export

To export the formation as an elementset

Copy

not yet functional

Attributes

To view or change the attributes of the formation like name or colour

Branches:

A formation contains of the following sub-branches with more detailed information about the formation:

Hexahedrons:

Horizons

The horizons defining the formation

Pressure

The assigned pressures per depletion stage

Strains

The assigned strains per depletion stage
Temperature The assigned temperatures per depletion stage

Planes

Top, Middle and bottom formation planes (mainly view planes)

Material

The assigned formation material parameter set

Tetrahedrons

Bodies The body name and mesh/colour properties

Pressure

Pressures in the formation for each depletion stage

Strains

The assigned strains per depletion stage

Temperature

Temperatures in the formation for each depletion stage
Material The formation material
