Pressure (fluid pressure)

The fluid pressures per depletion stage are shown in the formation branch, where fluids can be either water, brine, gas or oil. Default fluid pressures are taken from the branch "Global Pore Pressure" for both the initial stage and all subsequent depletion stages. This suffices if the fluid pressures remain hydrostatic and/or are irrelevant for the deformation mechanism (i.e. salt or layers which will not plastically yield).

The number of depletion stages (equal for all formations) are specified in the tab "Depletion Stages" of "Model attributes".

By selecting "Attributes" per formation and per depletion stage, a user can modify the pressure values or import pressure files via the use of point/element sets.

The pressure branch in a formation branch represents the pressures for the different depletion stages of the given formation.

Context sensitive menu

Right-clicking on pressure displays the same context sensitive menu as for Formation.
