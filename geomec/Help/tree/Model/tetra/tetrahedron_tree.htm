Tetrahedron Branch

The tetrahedron branch is the first main branch in the model tree located in the upper tree view of the GEOMEC tree. It shows the current state of the model. This branch appears when a tetrahedron type model is loaded, when tetrahedron is selected when a New Model is started or after converting a hexahedron model to a tetrahedron model.

Context sensitive menu

Right-clicking on tetradron in the tree, displays the following context sensitive menu::

Attributes

To view or change model attributes.

Branches

The tetrahedron branch contains the following branches:

Weight of seawater

Defines the pressure loading on the top of the model (sea floor).

Global pore pressure

Defines the global pore pressure situation.

Global temperature Defines the global temperature situation.

Gocad Sub Model

Defines Gocad Sub Model (surfaces and faults).
Horizons Defines all the non-GoCad horizons (usually empty).

Formations

Defines all the meshed or user-defined formations.

Boundary

Allows the setting of boundary conditions (mainly for a zoom-in model).
Analysis Points Contains all user-defined (post-processing) points for history views.

Cross sections

Contains all user-defined cross-sections for post-processing.

2D Results Allows import of a cross-section from a 2D analysis.

Wellpaths

Contains user-defined or imported well paths (vertical or deviated lines) for viewing and post-processing.

Scaling boxes Defines scaling boxes (mainly for zoom-in models).

If possible a selected tree item is visualized in the drawing area.
