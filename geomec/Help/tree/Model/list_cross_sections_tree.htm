Cross section

All the created cross sections are leafs of the cross sections branch:

Use insert cross section to define a new cross section.

Context sensitive menu

Right-clicking on a cross section displays the following context sensitive menu:

Change position

To graphically change the position of a cross section.

Copy

To copy a cross section (not supported yet).

Delete

To delete a cross section.

Attributes

To view or change the cross sections attributes.

A cross section can be viewed in cross section mode, but also in default and bird-view mode, the latter in combination with other viewable items such as wells, other cross sections or formations.

A cross section can be used to create a 2D model out of a 3D model. In that case it is assumed that no strains occur perpendical to the cross section (reflects infinite extension of model). Pressures and materials will be copied to the 2D version.
