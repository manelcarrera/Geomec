Strains

The strains per depletion stage are shown in the formation branch. They consist of a Volumetric strain, and a Full strain tensor or Normal/Lateral strains.

The Volumetric strain supersedes the (deprecated) Volumetric strain branch in the formation branch, and the latter will be ignored. If you want Geomec to use that Volumetric strain instead, then the strain branch cannot contain any Volumetric strain properties, and the default value in the Attributes needs to be set to "unused".

When a Full strain tensor or Normal/Lateral strains are defined, the Full strain tensor takes precedence over the Normal/Lateral strains, which will be ignored. Only one of each of these properties can be assigned per depletion stage.

The number of depletion stages (equal for all formations) are specified in the tab "Depletion Stages" of "Model attributes".

By selecting "Attributes" per formation and per depletion stage, a user can modify the default strain values.

The strains branch in a formation branch represents the strains for the different depletion stages of the given formation.

Context sensitive menu

Right-clicking on strains displays the same context sensitive menu as for Formation.
