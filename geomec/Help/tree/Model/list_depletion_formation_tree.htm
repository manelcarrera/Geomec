Depletion stage

The depletion stages are sub-branches of the pressure branch and temperature branch (which are under the formation branch). The names of the depletion stages correspond to the names supplied to the depletion stages in the Depletion stages tab, which is in the Attributes list of the model (Tetrahedron or Hexahedron).

Context sensitive menu

Right-clicking a depletion stage in the formation branch displays the following context sensitive menu:

Copy

Copies the depletion stage pressures or temperatures to be pasted in a different depletion stage and/or in a different formation branch
Attributes (pressure) To view or change information about the pressure in the depletion stage.

Attributes (temperature)

 To view or change information about the temperature in the depletion stage.
