Mesh converter

The Model tree represents the current state of the model. This is the upper tree view.

The selected tree items are visualized in the drawing area, if possible.

The Mesh converter consists of several branches:

Model

The definition of the type of 3D elements and internal structure.

Views

Choice of views of the drawing area.

Mesh results

Results describing the mesh quality.

Results

Results from the finite element calculation.

Derived results

Results derived from the 'normal' results.

User defined results

Results defined by the user.
