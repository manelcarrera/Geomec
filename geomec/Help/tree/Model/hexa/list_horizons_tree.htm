Horizon

All the created horizons are listed as sub-branches of the Horizons branch in the model tree. New Horizon is the default name of a horizon with constant depth.

Right-clicking on a created horizon displays the following context sensitive menu:

Attributes

To view or change the horizon attributes like color, depth or name.

Delete

Deletes the horizon.

Move down/up

To change the sequence of the horizons in the tree.

Copy

To copy the horizon (not supported yet).

 

There are a few methods to introduce Horizons into Geomec. Horizons are 2D surfaces which usually reflect interfaces between two material types or a change in other properties such as pressure. Also the upper mesh surface (usually the top surface, ie open air contact bottom of sea) and lower mesh boundary surface need be defined.

The lower surface is chosen such that the deformation of the rocks beneath this surface can be regarded negligible, due to depletion. The rocks should hence either have a very high stiffness K (for instance basalt or dolomite) compared to the overburden stiffness or be at sufficient depth beneath the reservoir or other depletion sensitive layers. Usually the lower boundary is chosen at 2-3 km beneath the lowest producing layer or at a convenient natural stratification.

A few methods to input Horizons exist:

  • constant Depth

  • input via an imported X, Y, Depth file

  • input via a GoCad or other predefined surface file

Procedure:

  1. Import external depth files via the DATA STORAGE menu.

  2. Create a horizon, preferably starting with the top horizon and work your way down. By right-clicking on the Horizon map, an option Box with " Create Horizon" appears. A new Horizon appears, called New Horizon #. 

  3. Click at the New Horizon and right-click to reach the Attributes button.

  4. Rename the horizon (for instance as Top Surface, Top Salt, Top reservoir) with a logical name.

  5. Attach a constant depth (in meters below top surface) or select one of the predefined layers in the lower box. If the desired layer is not in the box, the imported layer is not yet recognized as a layer. You should again reenter the DATA STORAGE module to fix this issue.

  6. You may want to change the color of the layer for visualization of the stratification afterwards.

  7. Proceed at 2 for the next deeper layer until you reached the lower mesh boundary

  8. If the layers do accidentally not line up from top to bottom:  use the Move up or Move down menu to fix this.

  9. Delete horizons which were entered incorrectly (or contain wrong imported values after visual inspection) or horizons which need to be removed to simplify the FE-model in hindsight (for instance to remove a thin layer or to average out two near identical material layers.

The Deletion of a horizon will result in the deletion of a formation. As a result the user will have to decide which formation should be deleted, especially when Material properties or Pressures were already assigned to a formation or layer (defined as the space in between two surfaces). User should always check the formation properties of the former upper and lower formation of the deleted layer, if these were assigned yet.
