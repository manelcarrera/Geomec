Hexahedron Branch

The hexahedron branch is the first main branch in the model tree located in the upper tree view of the GEOMEC tree.  It shows the current state of the model.  This branch appears when a hexahedron type model is loaded or when hexahedron is selected when a New Model is started.

Context sensitive menu

Right-clicking on hexahedron in the tree, displays the following context sensitive menu:

Attributes

To view or change model attributes.

Convert to tetramodel

To convert the hexahedron type model to a tetrahedron type model. Note that once converted the model cannot be converted back to a hexahedron type model.

Branches

The hexahedron branch contains the following branches:

Weight of seawater

Defines the pressure loading on the top of the model (sea floor).

Global pore pressure

Defines the global pore pressure situation.

Global temperature Defines the global temperature situation.

Horizons

Allows generation of horizons/surfaces.

Formations

Defines all the formations.

Boundary

Defines the boundary of the model. (Box in N,E,Depth directions).

Mesh

Defines mesh objects and parameters.

Analysis points Contains all user-defined (post-processing) points for history views.

Cross sections

Contains all user-defined cross-sections for post-processing.
2D results Allows import of a cross-section from a 2D analysis.

Wellpaths

Contains user-defined or imported well paths (vertical or deviated lines) for viewing and post-processing.
Scaling boxes Defines all the scaling boxes.

If possible a selected tree item is visualized in the drawing area.
