Wellpaths branch

Wellpaths is a branch of the model tree. It represents all imported/created wellpaths and 1D cross-sections.

Context sensitive menu:

Right-clicking Wellpaths displays the following context sensitive menu:

Insert deviated wellpath To insert any wellpath by reading in a Mores report file, Gocad XYZ wellpaths or general TXT or XLS wellpaths (arrays of coordinates of wellpath)
Insert vertical wellpath graphically To insert a vertical line through the model for viewing purposes. Select the "well" lateral coordinates graphically by clicking in the drawing area.

Insert vertical wellpath by value

To insert lateral coordinates by value by defining its Easting and Northing coordinates.

Note: The wells are basically 1 D cross-sections. Results can be viewed on the wellpath (Views \ 2D Linegraph). Results can also be exported on the wellpath, plotted on a Northing, Easting, Depth, AHD, results pointset.

Exporting wells is not (yet) possible. However,, by exporting data on wells, the wellpaths get exported. One just needs to delete the results columns to retrieve the wellpath as Northing-Easting-Depth or Northing-Easting-Depth-AHD array.

The 2D linegraph view represents the intersections of the wellpath with the element and formation boundaries it encounters for both vertical and deviated wells. These values cannot be exported.

The export routine on wells takes original coordinates of the wells to plot results on.

For further information on managing the properties or actions of separate wells, see wellpath.
