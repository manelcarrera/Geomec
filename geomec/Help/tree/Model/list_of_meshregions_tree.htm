Mesh regions

The mesh regions branch (only for Hexahedron Elements ) contains the main mesh region and optional sub mesh regions, to be added to the list.

Context sensitive menu

Right-click to get the context sensitive menu with the following options

Create mesh region; Rectangular Allows you to insert a rectangular mesh region by specifying two opposite corner points in the top-view.
Create mesh region; Polygonal Allows you to insert an arbitrarily shaped mesh region by specifying the points of a polygon in the top-view.
Attributes Invokes the Mesh attributes dialog.
