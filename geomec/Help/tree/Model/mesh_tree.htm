Mesh

Mesh is a branch of the model tree. This branch provides general information about the mesh.

Context sensitive menu:

Right-clicking on mesh in the model tree displays the following context sensitive menu:

New Mesh region

To create a new mesh region (either rectangular or polygonal).

Attributes

Displays the number of elements over the thickness per formation.

Branches:

Mesh contains the following leaves:

Main

Main mesh region.

Mesh region

Each created mesh region is displayed as a leaf of the mesh branch.
