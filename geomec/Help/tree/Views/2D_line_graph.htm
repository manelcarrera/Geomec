2D-Line graph view

2D-Line graph is a view mode of the model. You can plot results on basis of a line section, always called a well in Geomec. Select a Wellpath (or create imaginary vertical well first at the desired surface coordinates) and the Result you want to display.

The result will be plotted in a graph as a function of the depth along the wellpath.

In order to invoke the 2D-Line Graph view, select 2D-Line graph in the Views branch.

Right-clicking in the drawing area invokes a context sensitive menu with the following options:

True vertical depth

Results will be displayed as a function of the true vertical depth (TVD). 

Along vertical depth

Results will be displayed as a function of the along hole depth (AHD).

Formation depth lines

Toggles the formation depth lines on and off.

Markers

Toggles the Markers in the result line on and off.

Track coordinates

Toggles the coordinates (TVD / AHD, result) when moving along result line on and off .

Reset limits

To change or reset the limits of the 2D-line graph.

Copy picture

Copies the drawing area as a bitmap to the clipboard for later use.

Copy data  

Copies the function description to the clipboard for later use.
Enhanced frac. Grad. Enhanced fracture gradient obtained if loss prevention material (LPM) is used. The Enhanced fracture gradient is only relevant and calculated for sand layers (set in the formation attributes dialog). Its calculation is based on analytical formulae and can be derived from standard GEOMEC stress results and material properties. (Ref. Fuh et al. SPE 24599, "A new approach to preventing lost circulation while drilling")

Zooming in on a section of the graph can be done by clicking in the graph and dragging up or down. After release of the mouse button the graph is displayed in between the new limits.

Use Reset limits to view all available data.

Alternatively the zoom-in button in the view toolbar can be used to zoom in on the graph as well as the zoom in cursor to zoom in on a section.

Use zoom out to zoom out.

Use zoom-all to zoom to the entire graph.
