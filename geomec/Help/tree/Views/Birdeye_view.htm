Bird-eye view

The bird-eye view is a leaf of the Views branch in the model tree. The bird-eye view allows you to select an arbitrary number of geological entities that will be visualized together in the drawing area. When the bird-eye view is selected, check-boxes appear in front of most items in the model tree. All checked items will be visualized.

Results can be selected, so that they are mapped on the selected geological entities. It is also possible to view the entities using their color.

The view can be dynamically manipulated.

The View toolbar contains various options for the bird-eye view.
