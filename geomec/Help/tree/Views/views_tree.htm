Views branch

Views is a branch in the model tree. In the Views branch a view mode for the drawing area can be selected. The following views are available:

2D-LineGraph

2D line graph view, requires that a wellpath is selected as well as a result.

Bird-eye

Bird-eye view, viewable items can be switched on and off.

Cross section view

Cross section view, requires that a cross section is selected.

Default

Default view of the model.

History view 2D line graph view, requires that an analysis point is selected as well as a result

Topview

Top view of the model.
