Troubleshooting

GEOMEC uses DIANA Finite Element software to calculate results.

In most cases the DIANA analysis will calculate results. However, in some cases DIANA code may generate specific error or warning messages.

The variety of these messages is too large to explain them all in this context. General knowledge of the Finite Element Method is useful for interpreting the messages.

Some straightforward errors and warnings are listed below. In other cases the GEOMEC user is referred to the DIANA manuals (1)

 

  • Errors related to the operating system: read/write error.

The general form of such an error is: Trying to write to filosfile

Insufficient disk space available. Make sure that enough disk space is available for DIANA to write to.

 

  • Warnings related to the grid size

The general form of such an error is: Bad shaped element

Steep gradients in horizons or relatively thin formations combined with a large grid spacing (hexahedron type model) can cause strangely shaped elements in the model. In most cases refinement of the grid will eliminate this problem. Note that DIANA can still perform the finite element calculation. Results around the badly shaped elements are to be interpreted with caution, however.

(1) DIANA User’s Manuals, published by TNO DIANA BV, Schoemakerstraat 97, 2628 VK Delft, The Netherlands
