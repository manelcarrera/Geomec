Calculating in GEOMEC

GEOMEC currently supports five calculation modes,

  • Linear (►)calculations calculate the elastic response to loading only, i.e. this mode is not suitable in combination with a non-linear material model such as Cam Clay, Mohr Coulomb or salt creep. Since all non-linear models have linear parameters too, the linear option allows a quick review of the depletion effects, provided that the expected behaviour is not too different from elastic. It can also be used for problems finding when the non-linear run does not converge, for instance in looking for (massive) negative stresses in faults or formations, which cannot be handled well by Camclay or Mohr Coulomb models. Note: unloading elastic parameters in an load/unload analysis will not be used in Linear mode, since stiffness needs to be constant during all depletion stages and steps/iterations. Also Branches and Phases will be ignored.
  • Non-linear ( ►►) calculations allow all linear and non-linear deformation mechanisms. The success of the run is dependent on the non-linear run settings, like amount of steps and convergence norms (allowable errors at end of iteration to push for next step instead of a re-iteration on the same step .
  • Heat-flow (►) computes Heat Diffusion through Rock from Reservoirs and side surfaces through the model. Heat flow does not take convection into account (Heat carried by fluid flow). It is intended to a pre-analysis to Finite Element computation to compute heat flow in overburden and underburden, if not supplied by Reservoir Model
  • Mixture Flow (►►) computes (simultaneous) coupled Fluid flow (in non-reservoirs) and rock deformation.  It is intended for Finite Element computation to compute (single phase) fluid flow in low-permeable, but not impermeable overburden and underburden layers, if data is not supplied by Reservoir Model. It is a poor mans attempt to predict pressures in these layers, where a reservoir flow model would be preferred.
  • Containment Flow (►►) computes the effect of fluids permeating in discrete fractures into the non-reservoir rocks. One can now check on whether tensile effective stresses develop in the caprock, indicative for hydrofrac potential. Geomec will assume a high permeability (overwriting material permeability and a Grain Modulus close to the Bulk Modulus (low Biot number, to reflect low percentage of flooded pore space in hydrofrac mode) for the non-reservoir layers. Aquifers or other non-reservoir permeable rocks should be given an artificial depletion, for instance applying the global fluid gradient as local fluid gradient, so that Geomec/Diana does not modify pressures here.

With these non-linear deformation models a linear calculation should be used only for a comparison between the elastic and non-linear calculations.

To start a Finite Element analysis, select the appropriate command from the Analysis menu.
Alternatively:  use the black single forward arrow (►) button for linear, the black double forward arrow ( ►►) button for non-linear calculations, the red single forward arrow (►) for Heat Flow and the blue double forward arrow (►► or►►  ) for Mixture and Containment (fluid) flow.

If the model is not yet meshed, GEOMEC will automatically generate the finite element mesh. The Analysis commands are not available when the model is incomplete. To check the completeness of the model, use the Calculation criteria command.
