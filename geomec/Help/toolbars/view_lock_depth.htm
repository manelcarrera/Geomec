Lock Depth

The Lock Depth button in the Toolbar View locks rotation around the Depth axis. With the rotation locked around the depth axis, rotation is only possible around the easting and northing axis.

A locked axis can be recognized by its blue color. 

Only one axis can be locked at any time. Locking one axis automatically unlocks a possible other locked axis.

Use the Lock Easting command to lock rotation around the Easting axis.

Use the Lock Northing command to lock rotation around the Northing axis.

Use the Unlock command to unlock a locked rotation axis.
