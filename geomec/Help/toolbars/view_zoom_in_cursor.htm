Zoom in cursor

With the zoom in cursor button in the Toolbar View a zoom window can be defined to zoom in on a selected area of the current drawing. To indicate the zoom window, click in the drawing area to define the first corner of the zoom window and drag to create the window. After releasing the mouse button, the area inside the zoom window is scaled to fit in the drawing area as good as possible.

Use the Zoom in command to zoom in on the drawing.

Use the Zoom Out command to zoom out on the drawing.

Use the Zoom All command to view the entire drawing.

Dynamic Zooming is also possible.
