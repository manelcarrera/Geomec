Create mesh

A mesh can be created by clicking the Create mesh button in the Toolbar Analysis. For a hexahedron type model this button is enabled as soon as a formation is available in the model.

Use Mesh Attributes to define the number of elements trough the thickness of all the formations.

Use Main Mesh Region to define the grid size of the main mesh.

Use Mesh Region to define the grid size of the mesh region.

Use invalidate mesh to invalidate the mesh.
