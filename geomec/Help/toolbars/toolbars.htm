Toolbars

The toolbars contain buttons for fast access to most commands.

The following toolbars exist in GEOMEC:

General

Contains buttons for general project features.

View

Contains buttons for changing the display mode in the drawing area.

Analysis

Contains buttons for analysis features.

Topview

Contains buttons for actions executed in topview mode.

   

The toolbars can be toggles on and off in the View Menu.
