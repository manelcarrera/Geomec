Polygonal Mesh Region

The Polygonal Mesh Region is used to create a new mesh region. It is used to graphically insert a mesh region using a polygon.

Inserting a polygonal mesh region switches the view to the topview and displays the top horizon, if a mesh exists. If a mesh is non-existent click the create mesh button to create one (although it is possible to create a polygonal mesh region when no mesh exists). Click in the drawing area to start the polygon. Each click defines a point in the polygon. Right-clicking or pressing Esc. cancels the action. Clicking on the begin point closes the polygon and the new mesh region is defined. The attributes dialog box for the Mesh Region appears. Click on OK to finalize the new mesh region.

Inserting a new mesh region using a polygon can be invoked by:

  • Clicking the Polygonal Mesh Region button in Toolbar Topview.
  • Right-clicking on Mesh in the model tree and selecting new mesh region.
