Toolbar Analysis

The Toolbar Analysis consists of the following buttons for analysis purposes:

Create mesh

Creates the mesh.

Invalidate mesh

Invalidates the mesh.

Mesh Tolerance Allows the mesh tolerance to be specified.

Linear Depletion

Perform the linear depletion analysis.

Nonlinear Depletion

Perform the nonlinear depletion analysis.

Nonlinear Calculation Parameters

Displays the Nonlinear calculation parameters.

Consistency Guard

Displays the Consistency Guard overview and settings.

Use View Menu to toggle the Toolbar Analysis on and off.
