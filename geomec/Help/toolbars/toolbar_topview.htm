Toolbar Topview

The Toolbar Topview consists of the following buttons for actions executed in the topview:

Rectangular Mesh Region

To graphically insert a rectangular mesh region.

Polygonal Mesh Region

To graphically insert a polygonal mesh region.

Vertical well path

To graphically insert a vertical wellpath.

Insert cross section

To graphically insert a cross section.

   

In the View Menu the Toolbar Topview can be toggled on and off.
