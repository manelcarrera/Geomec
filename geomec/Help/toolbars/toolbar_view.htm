Toolbar View

The Toolbar View consists of the following buttons used for changing the view in the drawing area:

Zoom in

Zoom in on the current drawing.

Zoom out

Zoom out on the current drawing.

Zoom window

Zoom in on a selected area of the current drawing.

Zoom all

Zoom to the entire drawing.

Lock Easting

Lock rotation around the East axis.

Lock Northing

Lock rotation around the North axis.

Lock Depth

Lock rotation around the Depth axis.

Unlock

Unlock all rotation axes.

Vertical Exaggeration Exaggerate the vertical scale for cross-sections

Axis

Toggles the axis on and off in the drawing area.

Perspective

Toggles the perspective view mode on and off.

Fill

Toggles the fill view mode on and off.

Boundary

Toggles the bounding box on and off.

Lighting

Toggles the lighting on and off.

Local color scale

Use the local color scale.

Global color scale

Use the global color scale.

Hotspot

Use the hotspot color scale.

View Depth Direction

Change view direction to the Depth Direction.

View Easting Direction

Change view direction to the Easting Direction.

View Northing Direction

Change view direction to the Northing Direction.

Birdeye view

Change view direction to a birdeye perspective.
Copy Picture Copy the picture to the clipboard.

 Formation skin

Shows the formation skin only or the complete mesh

 

In the View Menu the Toolbar View can be toggled on and off.
