Birdeye view

The Birdeye View button of the Toolbar View resets the viewing direction to a birdeye perspective. Note: the view type is not changed to the birdeye view.

Use dynamic rotation to change the view direction dynamically.

 

Alternative view resets:

View Northing Direction to view the model in Northing direction.

View Easting Direction to view the model in Easting direction.

View Depth Direction to view the model in Depth direction.
