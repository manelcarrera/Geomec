Boundary Node Attributes dialog

This dialog allows you to specify the prescribed displacement for a selected corner node.

A corner node can have either

  • Zero displacement

No displacement is imposed on the corner node. This is the default

  • A local displacement vector

The given vector will be applied.

  • A displacement vector deduced from a global strain tensor

This option is only available if a global strain tensor has been specified. The displacement vector at each corner node is deduced from the global strain tensor taking the Reference point and the specified Reference line as fixed. See Prescribed displacements from a global strain tensor for a mathematical description.

If the "Apply to all corner nodes" option is checked the specified displacement option will be applied to all corner nodes in the model.
