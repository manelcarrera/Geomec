Interface attributes

The stiffness of the interface elements on the boundary can be set by right-clicking on “Boundary” and selecting “Interface Attributes”.

The user has a simple option for a zoom-in box, basically reflecting the analytical solution for the stiffness of a cylinder in an infinite space. Geomec applies the average model (brick) size  R ( =(L+W+H)/6 ) instead.

  • K-rad = K-normal = 3.04 * G / R
  • K-tan = K-shear  = 1.56 *  G / R  @  ½ * K-normal

The alternative is to manually set boundary stiffness conditions. 

  • A stiff (1E6 - 1E9 MPa/m) boundary element gives a domination of the deformation boundary condition, basically neglecting the applied stress boundary condition
  • A soft (0.001- 1 MPa/m) boundary element gives a domination of the stress boundary condition, basically neglecting the applied deformation boundary condition
Any mixed mode or mid range values is possible.
