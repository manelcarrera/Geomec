Global stress tensor

The applied stress changes on the boundary faces of the model can be specified through a single global stress tensor.

To specify a global stress tensor, open the "Boundary" tree node, and right-click its subnode "Boundary Conditions". A context sensitive menu appears with the option "Global stress tensor". Click the option, and the Global Stress Tensor dialog appears.

By default, the stress tensor is "Undefined". If this is the case, the options that use this tensor will not available. If the stress tensor was defined, and its state is set to "Undefined", all options that refer to the tensor are switched back to their defaults.

A stress tensor can be specified in two ways:

  • General

The Full Stress tensor is specified in terms of NN, EE, DD, NE, ND and ED (including shear components).

  • Vertical

Set the Half Stress tensor, assuming one principal stress is vertical. This options allows only rotation in the NE plane. The azimuth is the angle between the Northing axis and the Maximum horizontal direction. A positive rotation is towards the Easting axis.

If a stress tensor is specified in one way it will automatically converted to the other if the selection changes. If the selection changes from "General" to "Vertical" and the tensor contains shear terms in the vertical directions, these are set to zero.

The stress tensor needs to be set manually for each Depletion stage (drop down menu at the top).

See Specifying stress boundary conditions for more help on stress boundary conditions.
