Boundary Face Attributes dialog

This dialog allows you to specify the boundary conditions for a selected boundary face.

A boundary face can be either

  • Supported in Northing and Easting

Each mesh-node of the face will be supported in Northing and Easting directions. This is the default for all the side surfaces.

  • Normally supported

A single translation support is applied on each mesh-node of the face. The support is directed in the direction of the (local) normal vector of the face. The mesh-node will only be allowed to move in the plane of the face at that point. Note that the local normal vector is used. This means that in general support directions can vary over a single face. This is the default for the bottom surface.

  • Fully supported

Each mesh-node of the face will be supported in all three (Northing, Easting, Depth) directions.

  • Not supported

No translation supports are applied to the mesh-nodes of the face. This is the default for the top surface.

When this option is activated stress changes can be applied on the face. A stress change is applied in each depletion stage. There are two options:

  • Global stress tensor
  • Stress tensor Pointset (At the moment this function is disabled when there are no interface elements on the boundary)
  • Vertically supported

Each mesh-node of the face will be supported only in all Depth direction.

If the "Apply to all outer faces" option is checked the specified support option will be applied to all boundary faces.
