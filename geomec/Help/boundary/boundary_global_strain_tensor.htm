Global strain tensor

The prescribed displacements on the corner nodes of the model can be specified through a single global strain tensor.

To specify a global strain tensor, open the "Boundary" tree node, and right-click its subnode "Prescribed Displacements". A context sensitive menu appears with the option "Global strain tensor". Click the option, and the Global Strain Tensor dialog appears.

By default, the strain tensor is "Undefined". If this is the case, the options that use this strain tensor will not available. If the tensor was defined, and its state is set to "Undefined", all options that refer to the tensor are switched back to their defaults.

The global strain tensor can be specified in two ways:

  • General

The Full Strain tensor is specified (including shear components).

  • Vertical

Set the Half Strain tensor, assuming one principal strain is vertical. This options allows only rotation in the NE plane. The azimuth is the angle between the Northing axis and the Maximum horizontal direction. A positive rotation is towards the Easting axis.

If the strain tensor is specified, the "Reference line azimuth" must also be specified. This azimuth is 0 by default. The azimuth is the angle between the reference line and the Northing axis. A positive rotation is towards the Easting axis. See Prescribed displacements from a global strain tensor for a mathematical description.

If the strain tensor is specified in one way it will automatically converted to the other if the selection changes. If the selection changes from "General" to "Vertical" and the strain tensor contains shear terms in the vertical directions, these are set to zero.

The global strain tensor needs to be set manually for each Depletion stage (drop down menu at the top).

See Specifying prescribed displacements for help on attributing the global strain tensor to the relevant corner nodes.
