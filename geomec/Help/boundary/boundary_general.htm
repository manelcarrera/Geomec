Boundary conditions

In a tetrahedron model it is possible to set boundary conditions manually.

By default, all side surfaces are supported in Easting and Northing. The bottom surface is usually supported in normal direction, whereas the default for the top surface is "unsupported". The seawater pressure (to be specified as a gradient and a mean sea level) acts as a vertical stress on the top surface of the model, provided there exists a positive water depth. A negative water depth results in a zero top surface loading.

Before the boundary conditions can be specified, the following prerequisites must be satisfied.

  • at least one depletion stage (apart from the initial stage) exists
  • a mesh has been generated

When this is done, the two tree sub nodes under "Boundary" named "Boundary Conditions" and "Prescribed Displacements" will be enabled.

The user can change the supports when there are no interface elements on the boundary. There are no interface elements when right-clicking on “boundary ” and the context sensitive menu “Apply Boundary Interfaces ” is unchecked. When checked, interface elements are automatically added.

More information is given on setting boundary conditions in without using interface elements or with using interface elements.
