Stress tensor poinset

To apply a stress boundary condition the user may attribute (drag and drop) stress tensor (3D) pointsets to the Depletion Stages (leafs) in the Main Tree. Geomec will assign the stress tensor to the boundary nodes based on a nearest neighbour approach. The pointset hence does not necessarily needs to match the boundary nodes. At the moment this function is disabled, unless when working with Interface Elements.

Using the global stress tensor is another option to apply a stress boundary conditions.
