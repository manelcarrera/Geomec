Specify prescribed displacements

Before prescribed displacements can be specified some prerequisites must have been satisfied, see Boundary conditions.

There are two options to set prescribed displacements:

  • Deformation at the corner nodes

Open the tree node "Boundary" and select its subnode "Prescribed displacements". The model will be drawn in the Drawing area, showing only the separations between bodies at the sides and bottom of the model. Each point where multiple separations intersect is highlighted in blue, except the model's Reference point, which is highlighted in green. These points are called the "corner nodes". They can be selected by left-clicking on them. A selected corner node is colored red.

Select the corner node for which you want to specify prescribed displacements, and right-click on it. A context sensitive menu containing the option "Attributes" appears. Select the option, and the Boundary Node Attributes dialog appears. There are three options is this dialog:

  • Zero displacement
  • Local displacement vector
  • From global strain tensor

Unless the option "Apply to all corner nodes" is specified in the dialog, this process must be repeated for each corner node.

  • Deformation vector 3D pointset

The user may attribute (drag and drop) Deformation (3D) pointsets to the Depletion Stages (leafs) in the Main Tree. Geomec will assign the Deformation vector to the boundary nodes based on a nearest neighbour approach. The pointset hence does not necessarily needs to match the boundary nodes. At the moment this function is only available when working with Interface Elements on the boundary.

Note that only deformation in the direction of a Constraint will be prescribed. Deformation in an unconstrained direction (potentially a stress boundary condition) will be ignored. When there are no interface elements on the boundary you can change the supports on the boundary.
