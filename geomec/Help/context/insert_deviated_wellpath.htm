Insert deviated wellpath

Geomec allows the user to insert deviated wells by importing files. The user selects the well path branch in model tree and chooses insert deviated well path on the context menu. A file dialog appears and the user can select the following file formats:

  • Mores report file (*.mwr)
  • Gocad well files (*.mx)
  • ASCII (*.txt)
  • Excel (*.xls)
