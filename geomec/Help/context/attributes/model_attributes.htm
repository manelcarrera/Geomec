Model Attributes

The model attributes dialog is displayed by :

  •  selecting Model Attributes in the File Menu.

  •  right-clicking on Model type (Hexahedron or Tetrahedron) in the GEOMEC tree and selecting Attributes.  

The model attributes are used for general project information.

The model attributes dialog consists of the following tabs:

General

General project information.

Depletion stages

The number of depletion stages can be set here. Also the names of the depletion stages can be changed and  the time-frame in which the depletion stages occur can be set. Restart options can also be set including whether to produce result output for a particular depletion stage or not.

Model

General information about the model.
