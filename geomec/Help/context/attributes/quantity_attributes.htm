Quantity attributes

The quantity attributes dialog appears by right clicking on a property of a point/elementset in the data storage tree and selecting attributes. This dialog also appears by right clicking on a quantity in the distributed quantities table in the point/elementset attributes dialog.

 The quantity attributes dialog gives information of a quantity in a point/elementset.

 It consists of the following items:

Name

 Name quantity. Default name is equal to the property created in the Point/elementset attributes dialog. The name can be changed by renaming it.
Nr. of components Number of components of the quantity
Quantity type Type name of the quantity. This name equals the selected distributed quantity in the Point/elementset attributes dialog

A table is given with information per component. This table contains the following column items:

Name

Name quantity. A question mark is shown when no property is assigned to the component of the quantity.

Min Minimum value quantity
Max Maximum value quantity
Range Minimum allowed value for the quantity
Range Maximum allowed value for the quantity
Unit Used unit type.

 Use Point/Elementset Attributes to create or change the values of a component.

Weighting

Weighting is a element to element mapping option which only is available for element sets. There are four options:

Point interpolation

 Values at nodes of target elements obtained by linear interpolation within the elements of the source mesh
Unweighted averaging  
Voight averaging  
Reuss averaging
