Formation attributes

The formation attributes dialog appears by right-clicking on a Formation in the model tree and selecting attributes.

The formation attributes provides information about the formation.  

These attributes consist of three parts: General, Mesh and Formation type

General:

Name

Name of the formation. The default name can be changed by renaming it.

Formation color

The color of the formation in which it is displayed. The color can be changed by clicking on the colored square and selecting the desired color.

Top horizon (hexa only)

The name of the top horizon of the formation

Bottom horizon (hexa only)

The name of the bottom horizon of the formation.

Mesh (hexahedra models only):

Minimum layer thickness

The minimum thickness GEOMEC assumes a formation to be even if the distance between the top and bottom horizon is less than this value.

Number of elements

Number of elements GEOMEC will create in the depth direction.

If ‘Apply to all formations’ is checked, all formations assume the same settings for the minimum layer thickness and the number of elements.

Formation Type:

GEOMEC does not distinguish between material types (sands, clays, shales etc.) but the externally linked programs do.  Therefore it is wise to select the correct material per formation layer as well as assigning a material model (Cam clay, elastic etc.) and material properties (Youngs modulus, friction angle etc.).

Sands and shales are important material properties for data output.  FIST produces results for Sand and Sandstone formations only and these formations types are also used for the fracture gradient result (see 2D line graph).  Optimum mudweight analyses are carried out for shale type formations only.

Other present options are Chalk, Salt and Limestone.  Other formations types such as dolomite, magnesite, peat etc. should be left as 'Not Specified'.

GEOMEC does not warn for errors in the formation type assignment, such as selecting Salt for a pore collapsing material (Cam clay or modified Mohr-Coulomb) or combining a Sandstone type with creep parameters for salt.

Bodies (Tetrahedron models only)

A formation may contain several bodies i.e. volumes within the same formation separated by a fault or an intrusion.  The body colors can be varied but they must have the same material properties.
