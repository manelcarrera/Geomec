Formation plane attributes

The formation plane attributes dialog appears by right-clicking on a Formation Plane, a leaf of the Planes branch in a Formation branch, and selecting attributes.

Formation plane attributes provide information about the formation plane. The name and color of the formation plane can be viewed and changed.

 The attributes consist of the following items:

Name

Name of the formation plane. The default name can be changed by renaming it

Formation plane color

The color of the formation plane when it is displayed. The color can be changed by clicking on the colored square and selecting the desired color.
