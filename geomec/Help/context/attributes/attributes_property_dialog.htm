Quantity attributes dialog

The quantity attributes dialog is displayed by right-clicking on a quantity in the point/elementset attributes dialog. 

The dialog contains the following items:

Name Name of the quantity. Can be edited here.
Nr. of components Nr. of components assigned to the quantity.
Quantity type The quantity type.
List of components List of all components making up the quantity. Displayed are the component name, the minimum and maximum value of the component, the range in which the quantity can exist (e.g. 0 < Poisson ratio < 0.5) and the unit.
Weighting To select the type of extrapolation if extrapolation of the quantity is required.
