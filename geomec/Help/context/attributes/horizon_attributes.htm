Horizon attributes

The horizon attributes dialog can be displayed by right-clicking on a Horizon in the model tree and selecting Attributes.

The horizon attributes dialog provides information about a horizon:

General:

Name

Name of the horizon. The default name can be changed by renaming it. 

Color

The color of the horizon when visualized. The color can be changed by clicking on the colored square and subsequently selecting the desired color.

Enable slip

If checked, the horizon will act as slip layer. As a result, displacement between the upper and lower formation is allowed.

There are three different types of slip behavior possible:

  • Complete slip: This condition can be used in a linear analysis and will allow slipping between the formations at the interface with no frictional resistance. As the slipping formations have no frictional resistance the shear capacity result is not available for such a condition.

  • Complete stick: This condition can be used in a linear analysis and will allow slipping between the formations at the interface in accordance with the normal and shear stiffness of the interface calculated internally by the program. The friction angle and cohesion parameters entered are used only for post-processing in the calculation of shear capacity.

  • User defined: This condition can be used in a linear analysis however the friction angle and cohesion parameters are ignored in such a situation and the analysis is identical to a "complete stick" type analysis.  When used in a non-linear analysis the friction angle and cohesion parameters are used to determine the stress necessary to induce slippage between the formations in question.

Friction angle

Parameter used to describe the slipping behavior. Internal friction angle. 

Cohesion

Parameter used to describe the slipping behavior.

Top

Minimum z-coordinate of the horizon.

Bottom

Maximum z-coordinate of the horizon.

There are two types of horizons depending on the method of creation (see create horizon):

Constant depth

Horizon with constant depth.

Surface

Horizon created using a surface file.
