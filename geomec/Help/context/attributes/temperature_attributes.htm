Temperature attributes

The temperature attributes dialog appears by right-clicking on a Depletion stage in the temperature branch in the model tree.

All temperatures in all formations in the Initial stage are by default equal to the "Global Temperature", as input under the "Global temperature" branch.

For each formation and depletion stage which differs from these values (initially or during the depletion) a new temperature needs to be defined.

The temperature attributes provides information about these temperatures:

Depletion stage

Name of the depletion stage

Formation

Name of the formation

There are three temperature definition options. Activate one of these options:

  • 'Global temperature' for the initial stage or 'Same as previous depletion stage' for all other depletion stages
  • Distributed value
  • Single value

These temperature definitions are described below.

Outside set of distributed values use:

The temperaturecan be defined with a distributed quantity ‘temperature’ via a point- or elementset (see one of the options above). There are two options to define the value outside this distributed value:

Predefine temperature value

The temperature outside the distribution equals the global temperature value for the initial stage and same as previous depletion stage for all other depletion stages.

Extrapolated temperature value

The temperature outside the distribution equals the extrapolated temperature value of the distributed value.

A change in temperature definition between two subsequent depletion stages is considered to be depletion and the formation is assumed to be a reservoir. The icon of the formation in the formation branch changes from a formation icon into a reservoir icon.

Global temperature / Same as previous depletion stage

The global temperature definition is used to calculate an initial temperature situation (initial stage). Use Global temperature to define the global temperature.

Each (subsequent) depletion stage is (by default) taken to be equal to the previous temperature definition, which is the initial temperature for the first depletion step.

Same as previous depletion stage

Each (subsequent) depletion stage is default taken to be equal to the previous temperature definition. Therefore this definition can only be applied for depletion stages (not for the initial stage).

Distributed temperature

Distributed values can be imported as a point- or elementset or created within the Pointset attributes dialog via the RPN-calculator. After the distributed temperature is imported or created, it can be dragged onto a temperature leaf in the temperature branch in a formation branch in the model tree. This option can only be selected if the temperature file is imported and assigned as a temperature file, in which case the temperature file will be visible in a selection box at the bottom.
