Hotspot attributes

If a hotspot color scale is active and a result is currently displayed, the hotspot attributes dialog can be invoked by right-clicking in the legend area and selecting attributes. If another color scale is active, right-clicking in the legend area and selecting 'Create hotspot' will also display the hotspot attributes dialog.

Attributes for Hotspots shows the attributes of the hotspots. It consists of the following items:

Name

Name of the hotspot

Hotspot type

Select one of the two hotspot types

·          Two colored hotspot: a color for value less than defined minimum value and a color for values greater than maximum value.

·          Gradual color scale between the minimum and maximum value. Values greater than maximum value displayed with the maximum color.:

The values of the maximum and minimum ‘hotspot’ must be completed.

To change the color of  a hotspot, right-click on the colored square of the Min or Max value (between the two hotspot types) and select change color. Select the desired color and click on OK.
