Main mesh attributes

This dialog contains information about the main mesh region of the model. A model always contains a main mesh region, and optionally one or more sub mesh regions. The attributes for a sub mesh region can be viewed in the mesh region attributes dialog.

The main mesh region always encloses the entire model. The model's size is determined in the boundary attributes dialog. The main mesh region determines the grid size that can be used by sub mesh regions for mesh refinement sizes. Any elements in the main mesh region (and not in sub mesh regions) will be generated with this grid size. Elements generated in the sub mesh regions can be refined using powers of 2.

Grid size northing The size of the grid spacing in northing direction
Grid size easting The size of the grid spacing in easting direction
Colour The colour with which the main mesh region will be drawn

The grid size values will be rounded to the nearest value such that the model will always be meshed with equally sized elements.
