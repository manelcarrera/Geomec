Mesh attributes data storage

This mesh attributes dialog appears by right-clicking on mesh as a leaf of the 3D Point/Elementset branch in the data storage tree.

The dialog provides the following information about the current element mesh:

Number of nodes

Total number of nodes in current mesh
Number of elements Total number of elements in current mesh

Use Create mesh to create a mesh .

Use mesh attributes in the model tree to change the number of elements over the thickness for each formation.
