Surface attributes

The surface attributes dialog appears by right clicking on a surface in the tetrahedron model tree or in the datastorage tree and selecting attributes.

This dialog gives information about the surface.

The surface attributes dialog consists of the following items:

Name

Name of surface. The default name can be changed by renaming it.

Color

The color of the surface in which it is displayed. The color can be changed by clicking on the colored square and selecting the desired color.

Number of triangles Total number of triangles defined in the surface
Status Name of sub horizon for which the surface is used
Unit Select unit type: SI or FIELD

This option is only available when the surface is not used in the sub model. (The surface icon is not marked in the datastorage).
