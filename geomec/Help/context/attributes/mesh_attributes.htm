Mesh Attributes

Within the Mesh Attributes submenu you can review and adjust the number of Hexagonal Elements per Formations in vertical (depth) direction, especially after having inserted a mesh refinement in horizontal directions.

This dialog appears when right-clicking on mesh in the model tree and selecting attributes.

 It is sometimes easier to specify the full far field values within the Formation attributes, by adjusting per layer / formation the values and other data.

When you change these mesh attributes any present mesh becomes invalid. Use Create mesh to recreate a new mesh.
