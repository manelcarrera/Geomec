Sub horizon attributes

The sub horizon attributes dialog appears by right clicking on the sub horizon in the tetrahedron model tree and selecting attributes.

This dialog provides information about the attributes of a sub horizon.

 The attributes dialog consists of the following items:

Name

Name of sub horizon. The default name can be changed by renaming it.

Color

The color of the sub horizon in which it is displayed. The color can be changed by clicking on the colored square and selecting the desired color.
