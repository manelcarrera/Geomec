Formation attributes

The formation attributes dialog appears by right-clicking on a Formation in the tetrahedron model tree and selecting attributes.

The formation attributes provides information about the formation.  

These attributes consist of four parts: General, Formation type, Fluid Type and Bodies

 

General:

Name

Name of the formation. The default name can be changed by renaming it.

Formation color

The color of the formation in which it is displayed. The color can be changed by clicking on the colored square and selecting the desired color.

 

Formation Type:

In formation type a material type can be selected for the formation. This setting is only used by DStabor and FIST. DStabor uses this setting for optimum mudweight analyses, and that currently only the shale option is supported. In short this means that if optimum mudweight analyses are required for the formation, the formation type should be set to shale. The formation type should be set to sand to export points to FIST.

 

Fluid Type:

There are three options to select a fluid type:

Automatic (currently : Water)

 To select the default as fluid type. Oil/Gas is taken if depleted, water for no depletion.

Oil/Gas

 To select oil/gas as fluid type
Water To select water as fluid type

This option  is only needed for the definition of the pore pressure within faults. Pore pressure from water wet side is taken if there is a difference on each side of the fault (one side water and other side oil). Else, if 2 times oil or 2 times water, the pore pressure is set to the maximum of the two sides.

 

Bodies

A formation consists of one or more bodies. A table is given with information per body. This table contains the following column items:

Name

 Name body

Pressure

 Pressure from formation or initial pressure. This is only required  for 2D
Elements Total number of elements in body
