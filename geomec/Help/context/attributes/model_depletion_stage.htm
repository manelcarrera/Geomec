Depletion stages

The depletion stages tab is used for information about the depletion stages. This tab can be found in the Model Attributes dialog.

The depletion stages tab contains the following items:

Number of depletion stages

The number of depletion stages used for the calculation, including the initial stage, hence a minimum of 2 depletion stages.

 

Table with name, year, month and output

Corresponding to the number of depletion stages a table with the name and year/month of the depletion stages is shown. The year and month specification is important for non-linear analyses using a time dependent material model. The default year and month of the depletion stages can be changed by clicking twice on these items.

The Output column allows the user to specify whether results should be stored for the depletion stage ("Results" selected) or whether not to store results ("None" selected) or whether to create a branch for a subsequent restart analysis ("Branch"). See the Restart page for further information.
