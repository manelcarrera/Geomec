Attributes global color scale

If a global color scale is active and a result is currently displayed, the global color scale dialog can be invoked by right-clicking in the legend area and selecting attributes. If another color scale is active right-clicking in the legend area and selecting Create global gradient will also display the global color scale dialog.

The attributes for the global color scale consist of the following items:

Name

Name of the global color scale

Min value

Minimum result value used for the global color scale. Complete with the desired value. The current global minimum for the current result is taken as the default value. Smaller values will receive the color of the lowest value.

Max value

Maximum result value used for the global color scale. Complete with the desired value. The current global maximum for the current result is taken as the default value. Bigger values will receive the colour of the maximum value.

Find Extremes button

Find the current minimum and maximum result values and attaches the values to the Min and Max value.

The following options are available for changing the global color scale:

Change color

Right click on a color value below the color scale and select "change color  value". Select the desired color from the color box and click on OK.

Insert color value

Right click on a place between the minimum and maximum colors below the color scale and select "insert color"  to insert a new color value at the selected place.

Remove color value

Right click on a previously inserted color value and select "remove color value" to remove it. Note that it is not possible to remove the minimum and maximum color values.

Value of color value

Hovering above a color value with the mouse cursor displays the result value for that color.

Move color value

Inserted color values can be dragged (with clicked left mouse button) to a new place between the minimum and maximum value. The minimum and maximum values can not be moved.
