Fault attributes and initialisation

The fault attributes dialog appears by right clicking on a fault surface in the tetrahedron model tree and selecting attributes. It also appears for slipping surfaces in a Hexahedron Model, where the “enable slip” option is checked.

The fault attributes allows changing of the colour and fault-slip settings.

 

A fault in the model will act as an interface which allows slippage between material on either side of the fault.

There are three different types of slip behavior possible:

  • Complete slip: This condition can be used in linear and a nonlinear analysis and will allow slipping on either side of the fault with no frictional resistance. As the slipping materials have no frictional resistance at the fault the shear capacity result is not available for such a condition. Numerically, the fault is given an extremely low shear stiffness. The user cannot change the behaviour of slipping faults in a Phased or Staged non-linear computation.
  • Complete stick: This condition can be used in a linear and a nonlinear analysis and allows only for a small elastic displacement. Numerically, the fault is given an extremely high shear stiffness. The friction angle and cohesion parameters entered are used only for post-processing in the calculation of shear capacity. The user cannot change the behaviour of sticking faults in a Phased or Staged non-linear computation.
  • Mohr-Coulomb: In a linear run this option is identical to Complete Stick, although the user can set the elastic normal and shear stiffness parameters of the fault interface elements. In a non-linear run, the fault only slips if the shear stress is high enough to overcome the cohesion and friction (based on effective normal stress and friction angle). The user can set cohesion, friction and elastic stiffness parameters and change them in Phased or Branched analysis.
  • Fracture:  This option allows the interface as a fracture, switching normal stiffness to a very low value at (effective) tensile stress. The fracture can (presently) not also slip.

 

 

The faults have input leaves for

·       Fluid pressure (per depletion stage). Pressures are derived from the adjoining Tetrahedron (or Hexahedron) cells or overwritten by a used defined gradient, again to be overwritten by a (3D) pointset

·       Material parameters (for each Phase or Restart). Material parameters can be overwritten by a (3D) pointset

 

When running the model with User defined friction angle and cohesion the maximum shear stress is dependent on the effective normal stress in the fault and hence on the fluid pressure in the fault. The user is able to control the pressure in the faults in the following way:

·       Take for each fault element the maximum pressure from the two tetra elements that connect the fault element. The pressure hence changes with the settings of the neighbouring formation.

·       Take for each fault element the minimum pressure from the two tetra elements that connect the fault element.  The pressure hence changes with the settings of the neighbouring formation.

·       Take the maximum pressure seen in all triangles of a fault, corrected for fluid gradients. The minimum fluid density in the material library of tetra-elements is used for this. This option allows a worst case slip computation at for instance water injection, where water does not only pressurize the fault in the reservoir section, but also in the caprock and baserock.

·       The user can choose the option for all faults (Using Mohr-Coulomb) and all depletion stages, by changing the “Global Fault Behaviour”. Alternatively the setting can be changed per fault per depletion stage.

 

 

Fault pressures can be overwritten with user specified gradients and pointsets, where the options above are also overwritten. In this case:

·       Provide (per fault and per depletion stage) a pressure gradient.

·       Attach a pressure pointset to the fault. A nearest neighbour routine will be called to assign pressures to the fault elements. If a pressure pointset is attached, the user can choose to always use the nearest neighbour routine (use extrapolated points for the entire fault) or take a default outside the range (space) of the pointset

 

Fault Stress initialization for Mohr-Coulomb faults

The initial stress routine applies a linear-elastic routine to find the best match of Kh and KH stress ratio’s that are in stress (force) equilibrium. The faults are behaving elastic in this mode, by which it is possible the fault shear stresses are higher than possible according to the cohesion, friction and effective normal stress. As soon as the non-linear computations start the fault may have the tendency to release all this energy in one go, creating major problems in convergence. The user may also want to put the faults near failure initially or fully relaxed, to examine the extremes from the spectrum. Usually the initial fault stress in not known.

 

The user needs to choose from 3 strategies, from the Fault Initialisation Method button within the Fault&Fracture Settings. This method applies to all faults with Mohr-Coulomb behaviour.

·       the default being a shear stress-free (full slip) fault during initialisation. With larger faults, the fault slip may cause heavy distortions of the stress field and stresses that do not match the LOT data.

·       Geomec can increase the cohesion of the fault, if stress beyond the plastic limit. In this case the fault SCU (shear capacity utilization) is never higher than 1.0 and no stress redistribution is resulting from starting non-linear computation. This can result in an unrealistic high cohesion and near fault stress field

·       The initial fault pressure might be modified (decreased) by Geomec in order to move the stress level to the failure curve, provided they were exceeded during initialisation.  Within the initialization step (D0) non-linear steps are performed in order to stress release the fault to the plastic limits. Some stress reorientation occurs close the faults, that may be more realistic than with the options above.  At the end of D0 the pressures at the fault are again at the level that user supplied.  Geomec does not display the fault slip during this initialization, since it is not depletion/injection driven.
