Analysis point attributes

The analysis point attributes dialog appears by right clicking on an analysis point in the model tree and selecting attributes.

 This dialog gives information of the analysis point. An analysis point can be used in a history view.

The attributes dialog consists of the following items:

 

Name

Name of analysis point. The default name can be changed by renaming it.

Color

The color of the surface in which it is displayed. The color can be changed by clicking on the colored square and selecting the desired color.

 

Position

Northing

Northing coordinate of the analysis point

Easting

Easting coordinate of the analysis point
Depth Depth coordinate of the analysis point
