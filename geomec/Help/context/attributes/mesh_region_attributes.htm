Mesh region attributes

A sub mesh region can be defined on a part of the model. For this selected part the mesh can be refined. Refinements are always defined as powers of 2 with respect to the mesh grid size, defined in the main mesh region attributes dialog.

Name The name of the sub mesh region
Grid size northing The size of the element grid spacing in northing direction
Grid size easting The size of the element grid spacing in easting direction
Color The color with which the sub mesh region will be drawn
Formations / #Elements The number of vertical elements can be set per formation. Values can be 0 (no refinement in this formation) or a power of two of the #Elements of the formation.
