Model

The global stresses tab is used for some general information. This tab can be found in the Model Attributes dialog

The tab contains the following items:

Number of formations

Number of formations in the model

Number of faults

Number of faults in the model.

Number of nodes Number of nodes in the model
Number of elements Number of elements in the model

Gravity

Value for the gravity acceleration constant.

If you want to assign the gravity constant in the opposite unit type, (FIELD instead of SI or vice versa) click OK or Cancel (to ignore any changes made) and change the unit type by clicking on SI/FIELD in the status bar. Reopen the model attributes dialog, switch to the model tab and enter the value for the gravity constant in the new units.
