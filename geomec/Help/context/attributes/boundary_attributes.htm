Boundary Attributes

The boundary attributes dialog appears by right-clicking on the Boundary branch  in the Model tree and selecting attributes.

Boundary attributes is used for general information about the boundary. The color and dimensions of the boundary box can be viewed or changed.

The boundary box allows the user to set the mesh dimensions in the N and E directions. If some surfaces have been input with a consistent N,E, Depth file, the boundaries are usually pre-set in the required way, to include all NE-Depth data. However, the user may define the horizontal mesh extent to be smaller or greater than the predefined values. This is useful for instance if the geological input data contains too large an area or too small an area and the mesh needs to be extended to areas with no surface data, for instance to obtain the subsidence bowl, which stretches well outside the area of geological interest (reservoir and near-by regions).

The attributes of the boundary consist of:

Two options for defining the boundary dimensions:

Undefined The boundary is set to undefined as long as no model defining objects (model is empty) have been created (e.g. an horizon).

Best fit

The boundary is automatically defined around the model

Defined by user

Boundary defined by user. The coordinates (Northing and Easting) of the top and bottom corners which enclose the body of the boundary must be defined. The top corner has the minimum value for Northing and Easting, the bottom the maximum value (see figure below). The depth coordinates of these corner points are defined by the geometry of the model.

Boundary color

Color of the Boundary. This color can be changed by clicking on the colored square and selecting the desired color.

 

When no surface or N, E, Depth values are input for part of a defined surface, Geomec will extrapolate the layers to its mesh boundary by assuming a horizontal layer outside the supplied data field.

The general advice is to use Best-fit if consistent N, E, Depth values or surfaces have been imported, to be included in the model. If the imported dimensions are too large or too small (known beforehand or after a first meshing or calculation attempt) a user defined maximum-minimum is advised.
