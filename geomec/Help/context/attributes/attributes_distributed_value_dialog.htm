Distributed nodal value attributes dialog 

The distributed nodal values attributes dialog is displayed by right-clicking on a pointset property in the point/elementset attributes dialog.

The dialog consists of two parts. The fist part is the name, which can be edited here. The second part is a list of all points. Shown are the coordinates for each point (two for 2D pointset and three for a 3D point set) and the value belonging to the point.
