Formation volume attributes

The formation volume attributes dialog appears by right-clicking on a body in the tetrahedron model tree and selecting attributes.

The formation volume attributes provides information about a body.  

These attributes consist of the following items:

Name

Name of the body. The default name can be changed by renaming it.

Colour

The color of the body in which it is displayed. The color can be changed by clicking on the colored square and selecting the desired color.

 

Formation Name of the corresponding formation to which the body belongs.
