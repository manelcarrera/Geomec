Attributes local color scale

If a local color scale is active and a result is currently displayed, the local color scale dialog can be invoked by right-clicking in the legend area and selecting attributes. If another color scale is active first activate the local color scale  by right-clicking in the legend area and selecting 'Local'.

The local color scale attributes dialog displays the attributes for the local color scale.

The attributes for the local color scale consist of the following items:

Change color:

Right click on a color value below the color scale and select change color. Select the desired color and click on OK.

Insert color value

Right click on a place between the minimum and maximum colors below the color scale and select insert color value to insert a new color value.  

Remove color value

Right click on a previously inserted color value and select remove color value to remove it. Note that it is not possible to remove the minimum and maximum color values.

Value of color value

Hovering above a color value with the mouse cursor displays the result value for that color.  The value is a percentage of the total range between the minimum and maximum value. So the value of the left edge color equals 0% (=minimum result), the right color 100% (=maximum result)

Move color value

Inserted color values can be dragged to a new value. The minimum and maximum values can not be moved.
