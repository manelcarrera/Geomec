Attributes cross section

The cross section attributes dialog appears by right-clicking on a cross section in the model tree and selecting attributes.

The attributes of the cross section can be viewed and changed in this dialog box.

Name

Name of cross section

First Reference Point:

A reference point is the intersection point of the cross section line with the boundary of the model, marked in the drawing area with a green square.

Northing

Northing coordinate of First Reference Point.

Easting

Easting coordinate of First Reference Point

Second Reference Point:

 

Northing

Northing coordinate of Second Reference Point

Easting

Easting coordinate of Second Reference Point
