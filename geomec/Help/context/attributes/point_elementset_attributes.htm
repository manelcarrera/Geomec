Point/Elementset attributes

The Point/Elementset Attributes dialog appears by right-clicking on a Point/Elementset in the Data storage tree and selecting attributes.

The Point/Elementset Attributes dialog provides information about the pointset/elementset and its properties and quantities.

These attributes consist of five parts: Name, Properties & Quantities, Dimensions, Bounding box and 'Options'.

 

Name:

Name

Name of the point/elementset. The default name can be changed by renaming it.

 

Properties & Quantities:

This part consists of two tables: Unassigned properties and distributed quantities

 

Unassigned properties:

In this table the unassigned properties are listed.

Use 'Calculate property', the button just below this table, to create a new property. The RPN calculator appears and a new property can be defined. 

 Right-clicking on a property in the table, displays the following context sensitive menu:

Remove

To remove the property from the table.

Attributes To view or change the attributes of the property. The RPN calculator appears.

The created properties also appear in formulas, a leaf of the point/elementset in the datastorage tree.

 

Distributed quantities:

In this table the distributed quantities are listed.

Use the 'arrow-button', just below this table, to create a new quantity. A pull down menu appears with all the type of quantities that can be created. The quantity and its required component(s) appear in the distributed quantity table by clicking on the desired quantity type in the pull down menu.

The last selected quantity type is stored in the button just before the 'arrow-button'. The quantity type, labeled on this button, is selected by clicking on this button and added to the table. 

Double Click on a created quantity in the table to reveal (or vanish) its components. There are two marking options for the components. A question mark (in front if the component) is used for components with no property assigned. A property can be assigned by dragging and droping a property from the unassigned property table to a component of a quantity in the distributed quantity table. After assigning a property the question mark will be replaced by a ‘calculator’.

Right-clicking on a quantity in the table, displays the following context sensitive menu:

Remove

To remove the quantity from the table. The assigned quantity moves to the table of the unassigned properties.
Attributes To view the attributes of the quantity.

Right-clicking on a component, displays the following context sensitive menu:

Remove

To remove the property assigned to quantity from the table. The assigned property moves to the table of the unassigned properties.
Attributes To view or change the attributes of the property. The RPN calculator appears.

The created quantities also appear in properties, a leaf of the point/elementset in the datastorage tree.

 

Dimension

This part gives information about the dimension of the point/elementset. All the items are set in the point/elementset attributes.

1D

2D

3D

Given dimension of point/elementset: One of the three options is activated: 1, 2 or 3 dimensional.

Point size Total number of points of point/elementset
Element size Total number of elements of point/elementset. Value equals zero for a pointset.

 

Bounding box

This part gives information about the boundary box enclosing the point/elementset. All the items are set in the point/elementset attributes.

Min Coordinates (Northing, Easting, Depth) of the top corner of the boundary enclosing the pointset. The top corner has the minimum value for Northing, Easting and depth
Max Coordinates (Northing, Easting, Depth) of the bottom corner of the boundary enclosing the pointset. The bottom corner has the maximum value for Northing, Easting and depth

 

Options

The RPN calculator is used to define a property. The RPN system makes use of operands which can be numbers or values from outside the RPN calculator (e.g. coordinates or results). This part of the dialog gives information about the interpretation of these numbers and values.

There are two option to interpret the coordinates:

SI unit To interpret coordinates as SI units
Field unit To interpret coordinates as Field units

The same options are available to interpret the property values: 

SI unit To interpret values as SI units
Field unit To interpret values as Field units

There are two options to interpret the Z-Axis direction:

Up (Height) To set the Z-axis in upwards direction. The 'inversion' of the Depth coordinate are used. The depth values increases from bottom model to the top.
Down (Depth) To set the Z-axis in downwards direction. The 'default' of the Depth coordinates are used. The depth values increases from top model to the bottom.

This is particularly useful for point/elementsets imported from alien programs with a different convention for the geographical direction (E, N, D).
