View Settings

The View settings dialog is displayed by selecting Options in the View Menu.

In the View settings dialog the user can alter settings for the current view.

The following options are available:

Perspective

To display the model in perspective mode

Enable Rotate

To enable the dynamic rotation

Show Boundary

To display the boundary

Solid Fill

To display the model in Fill mode

Show Axis

To display the Axis.

Axis color

Color of the Axis. To change this color, click on the colored square, select the desired color and click on OK

Background color

Color of the Backgrounds. To change this color, click on the colored square, select the desired color and click on OK

Point size

Size with which points are drawn in the view

Apply to all views

To apply the settings to all views
