New Model

A new model can be initiated by clicking the new button in Toolbar General or by selecting new model in the File Menu. If an unsaved project is open the user will be asked to save it.

Next a dialog box will prompt the user to select what type of model the new model should be:

  • Hexahedron        brick elements with 8 corner nodes
  • Tetrahedron        pyramid elements with 4 corner nodes, required in combination with triangularized surfaces (from GoCad)
  • Eclipse                imported Eclipse reservoir model

After selecting one of the first two options, the appropriate (empty) model is created and the accompanying model tree and data storage tree can now be accessed. When selecting a new Eclipse model a dialog is opened in which the Eclipse model can be imported.
