Points used for FIST export

 

The dialog ‘Points used for FIST export’ is used to select analysis points in a well which will be exported to FIST.

 This dialog appears by right-clicking on a well in the tree and selecting Select points for FIST export.

There are two options for selecting analysis points:

 

Single point

One analysis point can be selected to export to FIST.

When selecting single point, the following item becomes active:

 

 

Position:

The position (AHD) of an analysis point can be typed in.

 

 

By clicking on Add to list, this point will be added to the list of all the selected points, visualized on the right-hand side of this dialog

 

Range

More analysis points, equally distanced within a range, can be selected to export to FIST.

When selecting Range, the following items become active:

 

 

From

The AHD of the beginning of the range

 

To

The AHD of the end of the range

 

Nr. of points

Total number of points within this range

 

 

Clicking on Add to list, these equally distance points will be added to the list of the selected points.

 

An overview of all the selected points are given in the ‘Selected points’ table. For every selected point the AHD and the name of the reservoir in which this point is localized, is shown.

Only points are added to the list if the selected points are in a reservoir specified as being sand.

Use Formation attributes to specify the formation (reservoir) type.

There are three buttons for processing and changing the list of selecting points:

Add to list

The point(s) specified in Single point or Range will be put into the list of selected points.

Remove from list

Select point(s) within the list, by highlighting them. By clicking on this button, these selected points will be removed from this list.

Add default

Five equally distanced points per reservoir (including the top and bottom of the reservoir) are added to the selected points.
