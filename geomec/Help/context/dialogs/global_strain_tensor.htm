Global strain tensor

The global strain tensor dialog appears by right-clicking on prescribed displacement, a leaf of Boundary in the tetrahedron model tree and selecting global strain tensor.

This dialog provides information about the global strain tensor.  

The global strain tensor dialog consist of the following items:

Depletion stage Name of depletion stage to define the global strain tensor.

There are three option to define a global strain tensor

Undefined Activate no global strain tensor.

Use Boundary node attributes to define a prescribed displacement per node.
General Activate a general global strain tensor. The following items become available by activating this option: The six component of the full global strain tensor.
Northing - Northing
 strain in Northing - Northing direction
Easting - Easting
 strain in Easting - Easting direction
Vertical - Vertical
 strain in Vertical - Vertical direction
Northing - Easting
 strain in Northing - Easting direction
Northing - Vertical
 strain in Northing - Vertical direction
Easting - Vertical
 strain in Easting - Vertical direction
Vertical Activate a vertical strain. This option allows only rotation in the Northing - Easting plane. The following items become available by activating this option:

Vertical

 strain in Vertical direction

Maximum horizontal

 maximum strain in Northing - Easting plane

Minimum horizontal

 minimum strain in Northing - Easting plane

Azimuth

 Angle between the Northing axis and the Maximum horizontal direction. A positive rotation is towards the Easting axis
Reference line azimuth If a tensor is specified, the 'Reference line azimuth' must also be specified. This azimuth is 0 by default. The azimuth is the angle between the reference line and the Northing axis. A positive rotation is towards the Easting axis.
