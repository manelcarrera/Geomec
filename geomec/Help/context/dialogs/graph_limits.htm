Graph limits

This dialog allows you to set the vertical or 'along the line' limits the 2-dimensional graph should display. Normally, the 2D graph displays the entire length of a wellpath. If you are only interested in a part of the range, you can drag a vertical range in the picture to set this range graphically. You can also set this range numerically in this dialog.

The two boxes allow you to set the minimum and maximum values.
