FIST export

 This dialog is used to select times during depletion for which certain values like reservoir pressures and stresses will be exported to FIST. From this dialog it is also possible to write the FIST file.

This dialog appears by right-clicking on a well in the tree and selecting Export to FIST. This context sensitive menu item becomes active when points are selected for FIST export (see Points used for FIST export) and a Geomec calculation has been performed.

The FIST export dialog consists of the following items:

 

Export points

List of selected analysis points. These points are selected in the ‘Points used for FIST export’ dialog.

 

Export dates

To select the times. There are two options to select a time:

 

 

Add date

To select a date.

Click on a date in the calendar and it will be added to the list of selected dates

 

Include stages

All the depletion stages defined in Geomec will be added to the list

 

An overview of all the selected times are given in the ‘Date’ table.

Newly selected times are not allowed to be before the initial depletion stage or after the final depletion stage as defined in the Geomec model.

Use Remove date to remove date(s) out of the selected date list.  

Use Export to write a FIST file for the selected points and times.
