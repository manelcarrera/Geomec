Nonlinear calculation parameters

The setting for nonlinear calculations (including Phased/Staged runs with linear elastic materials !) can be accessed via the Menu “Settings”  and the submenu “Nonlinear Calculation Parameters”. The settings also apply for Mixture and Containment Flow simulations. The dialog contains the following items:

Depletion stage calculation parameters   

Select the depletion stage for which the parameters are valid and then change the values if required. If the analysis is a restart analysis (from a branched project file) then the modification of the nonlinear calculation parameters will affect the depletion stages from the branched stage onwards only.

Automatic step size

Diana (FEM engine) will try to find the optimal step size for convergence. It will take a default of 0.3 (30%) of the total depletion step time as first time step. The user can change this. If convergence is not accomplished in the user supplied Convergence norm and maximum iterations, Geomec/Diana will restart with a smaller timestep (default: 30% of previous step). It will reduce the timestep upto 5 times (timestep roughly 0.001 of total time) and stop if still non-convergence occurs. If subsequent steps Geomec/Diana will increase step size if convergence occurs.

 

 

Manual step sizes
Number of steps:

Number of steps per depletion stage. The more non-linear the material parameters are and the higher the stress changes per time interval are, the more steps should be chosen to ensure convergence and accuracy.

Step scaling factor

Scaling factor for the first time step, with respect to equally sized time steps. The following steps have larger increments (equal additional increment to each step). The increment is chosen to be able meet the total time of the Depletion Stage. Example: A Depletion Stage lasts 12 month. The user selects 6 steps. The default step size is 2 months. With a scaling factor of 0.5, the first step is 1 month. The time increase will be 0.4 months (steps 1.0, 1.4, 1.8, 2.2, 2.6, 3.0 months: total 12 months.

Convergence norm value

Specifies the convergence criterion for the iteration process. This value is the tolerance for convergence.

Maximum number of iteration

The maximum number of iterations for each time step. This value depends on the iteration method. Geomec will perform this number of iterations if the convergence norm has not been satisfied.

Iteration scheme:

Choose one of the following iteration methods:

Constant: Invokes the Constant Stiffness method

Linear: Invokes the Linear Stiffness method. In principle, the same (elastic) stiffness matrix is used for all time steps and all iterations; this saves matrix (inversion) calculations but usually requires many more iteration steps.

Regular: Invokes a Regular Newton-Raphson iteration method. It sets up the tangential stiffness before each iteration.

Modified: Invokes a Modified Newton-Raphson iteration method. It sets up the tangential stiffness before the first iteration and subsequently keeps it constant during the iterations. As this method usually requires more iterations (than Regular), the preference between Regular and Modified is very dependent on the type of numerical problem.

Secant: Invokes estimates of stress corrections factors rather than iterations on the stiffness matrix. Method is slower, but more stable for highly non-linear processes like salt creep or Camclay. Try only when Regular does not give convergence, even with small steps.

Convergence norm type:

To specify the convergence criteria for the equilibrium iteration process. One of the following convergence criteria must be chosen:

Force: based on the external loading and out-of-balance forces

Displacement: based on displacements

Energy: based on internal energy

Defaults are convergence on Force with a criterion of 0.0001. See the link for further details.

Apply settings to all depletion stages (Checkbox)

Since it can be a tedious task to set all the parameters for each depletion stage separately, checking the 'Apply settings to all depletion stages' checkbox will assign the current parameters to all depletion stages once the OK button has been pressed.

Default button

Clicking the Default button sets all the parameters to the Default-values (10 steps per time interval, max 5 iterations, iteration on force with criterion 0.0001).

 

 

Set step to 1 for linear behaviour

If only linear elastic material models are found in the model, including faults, Geomec resets internally the total amount of steps to 1, since no stepping is required. For loading/unloading after a Phase/Restart, 2 steps will apply, including a small “testing” step

Loading/unloading

When selected, Geomec will perform a small step (1% of total depletion stage time) after each Phase or Branch (using compaction parameters) to determine whether an element is likely to compact or decompact. Based on this information, for decompacting cells, Geomec switches out compaction parameters for decompaction parameters, as defined in the material model. These decompaction parameters remain active until after a next Phase/Branch, even if the element grows into compaction mode once more.  Note:  nothing happens without Phases/Branches, even if you turned this option on.

Disable non-linearity in individual elements

Geomec/Diana can switch off non-linear behaviour in ill-shaped elements. These are usually very small elements (field scale default <1m3) or flat/needle-shaped elements (default < 3 degrees angle).  These elements may cause local divergence, but it is difficult to prevent them while meshing in small corners of the model. User can change settings.

 

Deformations

Large deformations

A large deformation analysis can be requested by checking this option.  When checked the non-linear relationship between displacements and strains is taken into account during the analysis procedure.  This type of analysis is also known as a geometric nonlinear analysis and therefore if this box is checked then a nonlinear analysis must be carried out to iterate on the solution even if linear elastic material parameters are used.  This type of analysis is usually only advised when very large deformations are expected which cause changes to the stress-strain response of the system.
