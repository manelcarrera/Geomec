Color scales

This color scale dialog displayed by:

  • Selecting color scale in the View Menu
  • Selecting color scale in the context menu by right-clicking in the legend area

The color scales dialog box is used to activate a local, global or hotspot color scale. It is also possible to create or delete a global or hotspot color scale or to view their attributes.

The color scales dialog contains the following items:

The possibility to activate a color scale:

Local

To activate the local color scale.

Global

To activate a global color scale, if available.

Hotspot

To activate a hotspot colors scale, if available.

For global color scales and hotspot color scales three options are available:

Attributes

Displays the attributes of the color scale selected in the combo box.  

New

Creates a new color scale. The attributes dialog of the appropriate color scale appears.

Delete

Deletes the color scale selected in the combo box.
