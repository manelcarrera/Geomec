Global stress tensor

The global stress tensor dialog appears by right-clicking on boundary conditions, a leaf of Boundary in the tetrahedron model tree and selecting global stress tensor.

This dialog provides information about the global stress tensor.  

The global stress tensor dialog consist of the following items:

Depletion stage Name of depletion stage to define the global stress tensor.

There are three option to define a global strain tensor

Undefined Activate no global stress tensor.

Use Boundary face attributes to define pressures per surface.
General Activate a general global stress tensor. The following items become available by activating this option: The six component of the full global stress tensor.
Northing - Northing
 stress in Northing - Northing direction
Easting - Easting
 stress in Easting - Easting direction
Vertical - Vertical
 stress in Vertical - Vertical direction
Northing - Easting
 stress in Northing - Easting direction
Northing - Vertical
 stress in Northing - Vertical direction
Easting - Vertical
 stress in Easting - Vertical direction
Vertical Activate a vertical stress. This option allows only rotation in the Northing - Easting plane. The following items become available by activating this option:

Vertical

 stress in Vertical direction

Maximum horizontal

 maximum stress in Northing - Easting plane

Minimum horizontal

 minimum stress in Northing - Easting plane

Azimuth

 Angle between the Northing axis and the Maximum horizontal direction. A positive rotation is towards the Easting axis
Reference line azimuth If a tensor is specified, the 'Reference line azimuth' must also be specified. This azimuth is 0 by default. The azimuth is the angle between the reference line and the Northing axis. A positive rotation is towards the Easting axis.
