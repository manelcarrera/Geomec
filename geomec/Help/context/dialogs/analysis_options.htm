Analysis Options

This dialog allows you to set options for the actual analysis being performed by the GEOMEC calculation kernel.

Element order The order of the generated elements. Quadratic elements contain extra nodes on the sides.
Use Enhanced Assumed Strain Method Whether or not the Enhanced Assumed Strain Method should be used.
Location of temporary files Determines the location of the temporary files, see below

If the "Location of temporary files" option is set to "Use TEMP environment variable" GEOMEC uses the system's location for temporary files. This location is stored in the TEMP environment variable. If this is not desired, or if this TEMP environment variable is not set, the option can be set to "User defined" and a location can be entered in the edit box, or the Browse button can be used to browse to the desired location.
