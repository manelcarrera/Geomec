Open Model

An existing model can be opened by selecting Open Model in the File Menu or clicking the Open button in the Toolbar General.

A file browser dialog is opened in which the user can browse to the right pathname to select the desired model. It is possible to open .gm5 (GEOMEC 5), .gm4 (GEOMEC 4), .gmp (GEOMEC 3) and .gm3 (GEOMEC 2) files.

If an unsaved project is open the user will be asked to save it.

Use Recent Files to open one of the most recently used projects.
