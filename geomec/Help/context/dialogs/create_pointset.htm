Create Pointset

This dialog allows you to create simple rectangular (2D) or cubic (3D) pointsets.

First, specify a name for the new pointset.

Second, select whether you want to create a 2-dimensional or a 3-dimensional pointset. Now, the two points spanning the entire pointset can be specified (see figure).

 

Finally, the density (number of points) in each direction should be provided.

Click the OK button, and the new pointset will appear in the data-storage tree.
