Select result

This dialog allows you to select a result or input property (e.g. from a pointset or elementset) to be used as an operand for the RPN calculator.

Select the 'input' button for input properties or the 'output' button for results. The tree will change accordingly.

The name of the new operand can be generated or set manually. This option can be controlled by the 'Generate name' button.

If a result is selected ('output'), the desired analysis mode (linear or non-linear) and depletion stage should be selected at the bottom.

Click OK to transport the selected result as an operand to the RPN calculator.
