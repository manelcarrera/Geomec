Create horizon

There are two types of horizons:

  • Constant depth
  • Horizon from surfaces

Constant depth

To create a horizon with a constant depth,  right-click on Horizons in the model tree and select create horizon. A Horizon attributes dialog appears for filling in general information about the horizon like name, depth and color.

After filling in the information and clicking on the OK button, a new horizon is created. The new horizon will be added to the Horizons branch in the model tree.

Surfaces

Surfaces created from pointsets in the Data Storage tree can be used to create horizons. There are two ways to do this:

  • Drag a surface from the ‘Data Storage’ tree to the ‘Horizons’ branch in the model tree
  • Right-click a surface in the ‘Data Storage’ tree and select ‘Create horizon’. A horizon is created from the surface. Default the horizon will take the name of the surface it was created with.

A horizon can be viewed in the drawing area by selecting it in the ‘Horizon’ branch in the model tree.
