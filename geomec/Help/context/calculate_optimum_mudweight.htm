Optimum mudweight

This dialog allows you to run the optimum mudweight analysis for selected points using the DStabor kernel.

The first three fields allow you to select the wellpath, depletion stage and calculation mode that should be used. The other three windows contain the selected values, the progress messages of the DStabor kernel, and the results per selected point.

The Start button starts the optimum mudweight analysis.

The Stop button allows you to stop the analysis in progress.

The Invalidate button allows you to delete any existing optimum mudweight results.

The Close button closes the dialog.
