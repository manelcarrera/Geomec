Insert cross section by value

To insert a cross section by value, right-click on the cross sections branch in the model tree and select insert cross section, by value.

Inserting a cross section by value automatically invokes the cross section attributes dialog. The reference points and name of the new cross section can be assigned here.

Use insert cross section graphically to insert a cross section graphically.

Cross sections will always intersect with the whole model. If a newly defined cross section line does not intersect the edges of the model, the cross section line is automatically extended.
