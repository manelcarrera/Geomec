Results export

This dialog allows you to export GEOMEC results, parameters, mesh results or user-defined results. The results can be exported on:

  • element sets (any imported element set, not necessarily matching the existing mesh). The default existent element set is the mesh (all elements of the existent mesh).
  • Formations, i.e. a selection of element subsets per selected Formation
  • 3D pointsets. Any 3D-pointset can be used to map results on. Points outside the mesh area will receive NaN (Not a Number) data.
  • Horizons.  Only Deformation (displacements) and Mesh Results can be exported. Horizons do not have stress or strain values, since they can be fully different at either side of the horizon.
  • Slipping Horizons / Faults.  These have Fault properties like pressure, fault slip, shear stress, cohesion and friction angle, since they contain interface elements.
  • Wells.  Element Results will be mapped on the existing pointset (like 3D pointset) for deviated results, where an automated selecting is taken for 1D cross-sections (called vertical wells).

The user can select several items (faults, formations, etc) at the same time. The user cannot always mix items (export on faults and formations at the same time).

In the upper-left part the geometrical entity on which the results should be mapped can be selected. When a part of the model's mesh is selected (e.g. a slipping horizon or a formation) no mapping needs to take place, the results are directly assigned, and the averaging options are disabled. If an external pointset or elementset is selected, mapping will take place. The averaging method should be specified (see below) and a depletion stage's deformation of the source (model) mesh can be specified.

In the upper-right part the results that need to be exported can be selected.

Note that the selection varies with the chosen mesh-entity (well, horizon, etc).

 

Tip: to export attributed material properties on a mesh or pointset, the user can make “User Defined Results” or “Derived Results” with only the relevant parameters like “Young’s Modulus” or “Preconsolidation Pressure”. 

The lower-right part allows you to select the depletion stages for which the results need to be exported.

In the lower-left part, the following options are available.

Calculation

The calculation mode(s) to be exported: linear, nonlinear, heat flow, mixture or containment mixture

SI / Field unit

Results can be converted to both SI and Field units during the export procedure

Averaging type

Disabled in Geomec 5.0 (too slow in other than nearest neighbor) Only when mapping on an external pointset or elementset. See averaging methods.

Cell export option

Choose between an elementset (export per element per node, ie 8 results per Hexahedron node) or midpoints of elements (3D pointset; 1 result per element)

Formation Names

The Formation Names (text strings) can be co-exported. Easy for external postprocessing (fi excel) Geomec cannot read text strings on a pointset back in.

Deformation

Allows you to use displacements of a certain depletion stage (in linear or nonlinear) to take the updated coordinates for mapping on pointsets or element sets. The coordinates of the pointset or elementset will NOT be updated by the deformation!

Export as hotspot

If a hotspot definition is selected here, the values will be exported in hotspot format, i.e. only having flags like COLD, HOT or a percentage of HOT to COLD.

 

To export to Gocad file format, please refer to Export to Gocad
