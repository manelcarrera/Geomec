Insert vertical wellpath graphically

To insert a vertical wellpath graphically, right-click on the wellpaths branch in the model tree and select insert vertical wellpath, graphically. Automatically the topview is the current view. Clicking in the topview defines the position of the new  wellpath, the wellpath must be defined inside the model. Automatically the wellpath attributes dialog is invoked where the coordinates of the newly created wellpath can be altered, if desired. The new wellpath is added to the Wellpaths branch in the model tree.

Use insert vertical wellpath by value to create a new wellpath directly via the wellpath attributes dialog.

Use insert deviated wellpath to insert a deviated wellpath.
