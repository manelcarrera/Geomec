Insert cross section graphically

To insert a cross section graphically, right-click on the cross sections branch in the model tree and select insert cross section, graphically. Automatically the topview is the current view.

Click in the drawing area to define the begin point of the cross section line. Now drag the mouse cursor into the desired direction of the cross section line and release the left mouse button to define the end point of the cross section line. Automatically the cross section attributes dialog is invoked for the newly created cross section. Adjust the coordinates of the reference points if desired and click Ok. The new cross section is added in the cross sections branch in the model tree.

Use insert cross section by value to insert a cross section numerically, using the cross section attributes dialog box directly.

Cross sections will always intersect with the whole model. If a newly defined cross section line does not intersect the edges of the model, the cross section line is automatically extended.
