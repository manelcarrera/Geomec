Select points for DStabor analysis

This dialog allows you to select the points for which a DStabor analysis will be performed to obtain the optimum mudweight.

There are three ways to add points to the list of points that will be processed by DStabor.

  • Single point
 Add a single point at a given Along Hole Depth to the list. Enter the desired Along Hole Depth value and click the 'Add' button.
  • Range
 Add a range of points, starting and ending at given Along Hole Depth values, and given the number of points to add. Enter the desired starting and ending Along Hole Depth Values and the number of points that should be added and click the 'Add' button.
  • Add default
 To add default points to the list. These are typically the intersections with the horizons and extremes. Click the 'Add default' button to add the default points to the list.

The list contains all currently selected points, their Along Hole Depth values, and the formations in which they are located. Formations which have a Formation Type (under Formation > Attributes) other than Shale or Unknown will be skipped.
