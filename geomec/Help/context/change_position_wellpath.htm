Change position wellpath

The position of a previously defined wellpath can be changed graphically. Right-click on the desired wellpath name in the model tree and select change position. Left-click on the green square in the drawing area representing the selected wellpath and drag it to a new position. Left-click somewhere else in the view to assert the new position.

Use attributes to view the wellpath attributes.

Use insert vertical wellpath by value to create a new wellpath directly via the wellpath attributes dialog.

Use insert vertical wellpath graphical to insert a wellpath graphically.

Use insert deviated wellpath to insert a deviated wellpath.

Use delete to delete a previously created wellpath.
