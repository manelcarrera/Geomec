Units

Two unit types are available in GEOMEC:

  • SI-units
  • FIELD-units

To switch from unit type you click on SI or FIELD in the status bar.

For each imported file, for example horizon or pressure file, the unit type can be specified. This can be done by using a ‘unit flag’ in tagged files formats. If no unit is specified the unit is set to SI.

In tagged file formats the keyword UNIT is optional and can have the following values:

UNIT = FIELD

For FIELD units.

UNIT = SI

For SI units.
