Distributed value

Using the Pointset Attributes distributed quantities with distributed values can be created. The distributed values can be created using the RPN-calculator or they can be imported and attached to specific quantities.

For values outside the point- or elementset two options are available. In this situation the pointset or elementset does not enclose the whole object (e.g. formation)  to which the distributed value is attached. The two options are:

Use predefined values  for predefined values

Use extrapolated values for extrapolated values
