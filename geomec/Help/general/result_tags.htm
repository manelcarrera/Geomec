Scalars (like minimum stress) or vectors (like deformation) are represented by their size with the subscript L (Length). The direction is represented by a vector having a total length L and decomposed vectors in North (N), East (E) and Depth (V). A displacement vector of (N,E,V = (3,4,0)) will have a N value of 3, an E value of 4, a V value of 0 and a L value of 5 (=sqrt(32 + 42 + 02)).

The result tags can be extended with tags for depletion stages and are either linear or non-linear. The tag Dn is used for depletion stage n where n = 0 for the initial depletion stage. The tag L is used for linear and the tag N for non-linear. The tags are separated by underscores.

Example:

[RESULT_TAG]_D0_L       # depletion stage 0 (initial) and linear

[RESULT_TAG]_D1_N       # depletion stage 1 and non linear
