Distributed quantities

A point- or an elementset can be assigned to a quantity resulting in a distributed quantity. This can be done through the point/elementset attributes dialog. Distributed quantities can be assigned to all sorts of objects, a pressure quantity can be assigned to a pressure, a Young's modulus quantity can be assigned to a material and a surface quantity can be used to create a horizon, to name but a few ( for all available quantities see the pull down menu of distributed quantities in the point/elementset attributes dialog).

Assigning a distribution set to a quantity in the point/elementset attributes dialog

If the previously read in distribution set is untagged, no distributed quantities are available in the list of distributed quantities in the point/elementset attributes dialog. If on the other hand a tagged distribution set has been read in, the quantities belonging to the tags are available in the list of distributed quantities and the distribution has been assigned to the quantity (visible by double clicking the quantity).

If the distribution is untagged, first a quantity needs to be selected in the pull down menu. Double-clicking the newly added quantity opens it and shows the question mark meaning that no distribution has been assigned to the quantity. From the list of property distributions on the left, a distribution can be dragged onto the question mark. Now the property distribution is assigned to the selected quantity.

Right-Clicking the property distribution and selecting attributes will display the distributed nodal value attributes dialog if the distribution is a pointset and the distributed element value attributes dialog if the distribution is an elementset.

Right-clicking a distributed quantity and selecting attributes will display the property attributes dialog.
